自动控制理论 HTML 课件 — 播放说明（第一~四章 v1.0 验收版）

【Windows 快速播放】
1. 解压本压缩包到任意目录（路径含中文一般也可以）。
2. 双击 start.bat：
   - 若电脑装有 Node.js：自动启动 server.js 并打开浏览器；
   - 若没有 Node.js 而有 Python：自动用 python -m http.server 打开。

【macOS 快速播放】
1. 解压本压缩包到任意目录。
2. 双击 start.command：
   - 若装有 Node.js：自动启动 server.js 并打开浏览器；
   - 若没有 Node.js：自动用系统自带的 python3 打开。
3. 若首次双击 start.command 被系统拦截（提示"无法打开"或"来自 unidentified 开发者"）：
   在「终端」中进入本目录，执行一次：
     chmod +x start.command && ./start.command
   或者在 start.command 上点右键 →「打开」→ 确认。
4. 也可以不使用脚本，直接在「终端」进入本目录后执行：
     node server.js --port 7100        （装有 Node.js 时）
   或
     python3 -m http.server 7100       （macOS 自带 python3）
   然后浏览器访问 http://127.0.0.1:7100/ （python3 方式请访问
   http://127.0.0.1:7100/player/index.html ）。

【Linux 播放】
终端进入本目录，执行 bash start.sh，或参照上面 macOS 的手动命令。

【播放器操作】
浏览器打开后即为 Course Player：
  ←/→ 翻页；Space 推进分步动画；F 全屏；R 重置本页；Esc 退出全屏。
点击右上角「导航」可打开页面导航：显示每页编号与内容关键词，
点击任一页面即可跳转，也可返回当前页。

【注意】
- 不要直接双击 player/index.html 用 file:// 打开（浏览器会拦截本地 JSON 读取），
  必须通过上面的本地服务器方式访问。
- 全部内容为纯 HTML/CSS/JS，数学公式字体（STIX2）与插图均已内嵌，
  离线可用；Windows / macOS / Linux 显示效果一致。
- 本版本内容：
  · 第一章 自动控制概念（35 页）：先导概述、开环/闭环/复合控制、
    系统组成与分类、基本要求（稳·快·准）；含 2 页课堂互动题。
  · 第二章 控制系统的数学模型（51 页）：微分方程、拉氏变换、传递函数、
    方框图等效化简、信号流图、梅逊公式；含方框图化简、方框图↔信号流图
    转换、梅逊公式数回路三个重点交互动画页，另有 4 页课堂互动题。
  · 第三章 线性系统的时域分析（85 页）：典型输入与性能指标、一阶/二阶
    系统响应、劳斯判据与稳定性、稳态误差；含二阶系统参数-根-响应联动
    等重点交互动画。
  · 第四章 线性系统的频域分析（83 页·初稿）：频率特性与极坐标图、
    对数坐标图（Bode）、映射原理与 Nyquist 判据、稳定裕度、等 M/等 N 圆、
    Nichols 图、频域指标与时域指标关系；含 s 域→F(s) 域映射联动动画、
    等 M 圆滑块实验、ζ 联动实验等交互动画。
- 课堂互动题统一为：先显示全部选项，按键后高亮正确答案并给出解释。
- 公式采用 MathJax + STIX2 数学字体渲染，方框图相加点统一为「圆圈内 × 叉」。
- 插图由 AI 图像引擎重绘；旧 PPT 素材仅保留二维码与教材封面两张功能性图片。
