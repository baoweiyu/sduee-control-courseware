# 《自动控制理论》三层 HTML 交互课件

面向课堂教学的《自动控制理论》交互式课件系统：由传统 PPT 素材重构为**可离线播放、可 Web 部署**的三层 HTML 课件（播放器层 / 章节数据层 / 主题组件层）。

当前 **V3.1** 已发布第一至第八章，共 **468 页**；后续章节将随课程进度继续制作并发布到本仓库。V3.1 进一步复核了第八章描述函数、自振参数与稳定性的数学表述。

## 课件由来

本课件源自课程组多年使用的 PowerPoint 教学素材（PDF 导出稿），经内容拆解、版式重设计与交互化改造后重构为 HTML：

- **公式规范重排**：本地 MathJax + STIX2 数学字体，不依赖在线公式服务；
- **框图与曲线重绘**：传递函数框图、Nyquist/Bode 曲线、根轨迹等按数学关系绘制；
- **重点知识交互动画**：方框图化简、梅逊公式、参数联动、Nyquist 映射、根轨迹生长、校正设计步骤等；
- **AI 生成配图**：章节封面与部分工程实例使用图像生成引擎重新制作。

开发过程以 **Kimi K3 模型（Kimi Work 智能体）为主**完成，并结合多轮课堂教学反馈、理论复核、数值回归与视觉审查持续修订。制作经验沉淀于 `specs/制作规范与历史问题清单.md`。

## 使用方式

**本地离线播放**：下载 Releases 中任一章节 zip，解压后双击 `start.bat`（Windows）或 `start.command`（macOS）；Linux 可执行 `bash start.sh`。

**Web 部署**：下载 `act-courseware-web-deploy` zip，保持目录结构上传至任意静态托管。必须通过 HTTP(S) 访问，详见包内 `DEPLOY-部署说明.md`。

**播放器操作**：

- 方向键 / PgUp / PgDn / 空格 = 上一步或下一步，步尽后自动翻页，兼容常见翻页笔；
- 底栏「上一页 / 下一页」直接翻页，「上一步 / 下一步」优先控制动画；
- `N` 打开页面导航，`F` 全屏，`R` 重置本页。
