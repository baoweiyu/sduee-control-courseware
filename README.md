# 《自动控制理论》三层 HTML 交互课件

面向课堂教学的《自动控制理论》交互式课件系统：由传统 PPT 素材重构为**可离线播放、可 Web 部署**的三层 HTML 课件（播放器层 / 章节数据层 / 主题组件层）。**课件按章节持续制作中**：目前已完成第一~四章共 **258 页**，后续章节将随课程进度陆续制作并发布到本仓库。

## 课件由来

本课件源自课程组多年使用的 PowerPoint 教学素材（PDF 导出稿），经系统性的内容拆解、版式重设计与交互化改造后重生为 HTML 形态：

- **公式全部重排**：MathJax 渲染 + 本地 STIX2 数学字体，达到教材级排版效果；
- **框图/曲线全部重绘**：横平竖直的传递函数框图、严格按比例绘制的 Nyquist/Bode 曲线；
- **重点知识交互动画**：梅逊公式数回环支路逐步演示、方框图等效化简分步拆解、二阶系统参数联动、映射原理左右域同步动画等；
- **AI 生成配图**：大量示意图由 image2 图像生成引擎重新绘制，替代原始 PPT 截图。

开发过程以 **Kimi K3 模型（Kimi Work 智能体）为主**完成：从素材解析、页面生产、图像生成、交互动画编写到多轮课堂验收修复，历经 V0.9 初稿 → V2.16 共十余轮迭代打磨，全部修改经验沉淀于 `specs/制作规范与历史问题清单.md`（120 条规范）。

## 使用方式

**本地离线播放**：下载 Releases 中任一章节 zip，解压后双击 `start.bat`（Windows）或 `start.command`（macOS）。

**Web 部署**：下载 `act-courseware-web-deploy` zip，作为纯静态站点上传至任意静态托管即可（必须 http(s) 访问，详见包内 `DEPLOY-部署说明.md`）。

**播放器操作**：方向键 / PgUp / PgDn / 空格 = 上一步/下一步（支持翻页笔）；底栏按钮直接翻页；F 全屏；右上角「导航」按页码跳转。
