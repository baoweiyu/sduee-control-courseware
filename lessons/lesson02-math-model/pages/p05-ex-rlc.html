RLC 串联电路（实验板）
电路原理图
① 定输入输出u_{i}(t) \text{—— 输入量，}u_{o}(t) \text{—— 输出量}
② 列写方程由基尔霍夫定律：u_{R} + u_{L} + u_{C} = u_{i}，且 u_{R} = R\cdot i(t)，u_{L} = L\dfrac{di(t)}{dt}
③ 消元标准化考虑 u_{C} = u_{o}，i(t) = C\dfrac{du_{o}}{dt}，得 LC\dfrac{d^{2}u_{o}(t)}{dt^{2}} + RC\dfrac{du_{o}(t)}{dt} + u_{o}(t) = u_{i}(t)；令 T_{1} = L/R，T_{2} = RC，即 T_{1}T_{2}\cdot u_{o}'' + T_{2}\cdot u_{o}' + u_{o} = u_{i}
