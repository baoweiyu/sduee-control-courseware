① 线性定理\text{若} \mathcal{L} [f_{1}(t)]=F_{1}(s)\text{，}\mathcal{L} [f_{2}(t)]=F_{2}(s)\text{，则} \mathcal{L} [a\cdot f_{1}(t)+b\cdot f_{2}(t)] = aF_{1}(s) + bF_{2}(s)
② 微分定理\mathcal{L} [f'(t)] = sF(s) - f(0)
\mathcal{L} [f''(t)] = s^{2}F(s) - s f(0) - f'(0)
\mathcal{L} [f^{(n)}(t)] = s^{n}F(s) - \sum _{k=1}^{n} s^{n-k}f^{(k-1)}(0)
③ 积分定理\mathcal{L} [\int f(t)dt] = \dfrac{F(s)}{s} + \dfrac{f^{(-1)}(0)}{s}
\mathcal{L} [\int_{0}^{t}\!\!\int_{0}^{\tau} f(\tau )d\tau dt] = \dfrac{F(s)}{s^{2}} + \dfrac{f^{(-1)}(0)}{s^{2}} + \dfrac{f^{(-2)}(0)}{s}
④ 位移定理\text{实位移：}\mathcal{L} [f(t-\tau )] = F(s)\cdot e^{-\tau s}
\text{复位移：}\mathcal{L} [e^{-at}f(t)] = F(s+a)
⑤ 终值定理\lim _{t\to \infty } f(t) = \lim _{s\to 0} sF(s)
条件：sF(s) 的极点都具有负实部
⑥ 初值定理\lim _{t\to 0^{+}} f(t) = \lim _{s\to \infty } sF(s)
关键：零初始条件下微分定理简化为 \mathcal{L} [f^{(n)}(t)] = s^{n}F(s)——微分方程瞬间变代数方程。
