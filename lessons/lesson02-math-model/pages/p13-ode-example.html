例：求解 ÿ + 5ẏ + 4y = u(t)，u(t) = 2e−2t，y(0)=0，ẏ(0)=0
① 拉氏变换(s^{2} + 5s + 4)Y(s) = \dfrac{2}{s + 2}
② 求 Y(s)Y(s) = \dfrac{2}{(s+1)(s+2)(s+4)}　= \dfrac{2/3}{s+1} - \dfrac{1}{s+2} + \dfrac{1/3}{s+4}　（部分分式展开）
③ 反变换y(t) = \dfrac{2}{3}e^{-t} - e^{-2t} + \dfrac{1}{3}e^{-4t}　（稳态解 0 + 暂态解）
用 MATLAB 验证（residue 部分分式）
num = 2;
den = poly([-2; -1; -4]); % 分母的根
[r, p, k] = residue(num, den)
r = 留数向量（1/3, −1, 2/3）
p = 极点（−4, −2, −1）
k = 直项（本例为空）
