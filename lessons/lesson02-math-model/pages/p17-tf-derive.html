① 设系统微分方程的一般形式a_{n}c^{(n)}(t) + a_{n-1}c^{(n-1)}(t) + \cdots + a_{0}c(t) = b_{m}r^{(m)}(t) + \cdots + b_{0}r(t)
② 记 C(s)=L[c(t)]，R(s)=L[r(t)]
当初始条件均为零时取拉氏变换(a_{n}s^{n} + a_{n-1}s^{n-1} + \cdots + a_{0})C(s) = (b_{m}s^{m} + \cdots + b_{0})R(s)
③ 令 G(s) = C(s)/R(s)
—— 称为系统的传递函数G(s) = \dfrac{C(s)}{R(s)} = \dfrac{b_{m}s^{m} + b_{m-1}s^{m-1} + \cdots + b_{1}s + b_{0}}{a_{n}s^{n} + a_{n-1}s^{n-1} + \cdots + a_{1}s + a_{0}}(n \ge m)
一句话：零初始条件下，把微分方程中的 d/dt 换成 s，传递函数立即写出。
