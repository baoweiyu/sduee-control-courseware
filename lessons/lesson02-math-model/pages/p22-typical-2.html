3、积分环节
c(t) = K\int r(t)dt
G(s) = \dfrac{C(s)}{R(s)} = \color{#D63A2F}{\dfrac{K}{s}}
\text{单位阶跃：}c(t) = K\cdot t\text{，}t \ge 0
输出随时间线性增长（斜坡）
4、振荡环节
T^{2}\dfrac{d^{2}c(t)}{dt^{2}} + 2\zeta T\dfrac{dc(t)}{dt} + c(t) = K\cdot r(t)
G(s) = \color{#D63A2F}{\dfrac{K}{T^{2}s^{2} + 2\zeta Ts + 1}} = \dfrac{K\omega _{n}^{2}}{s^{2} + 2\zeta \omega _{n}s + \omega _{n}^{2}}
\text{极点：}p_{1,2} = -\zeta \omega _{n} \pm j\omega _{n}\sqrt{1-\zeta ^{2}}\text{，}0 \le \zeta < 1\text{，}T = 1/\omega _{n}
