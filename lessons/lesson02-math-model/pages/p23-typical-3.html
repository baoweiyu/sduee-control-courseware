5、微分环节
\text{\textbf{理想：}}c(t) = K\dfrac{dr(t)}{dt} \Rightarrow G(s) = \color{#D63A2F}{Ks}
\text{\textbf{一阶：}}c(t) = K[\tau \dfrac{dr(t)}{dt} + r(t)] \Rightarrow G(s) = \color{#D63A2F}{K(\tau s + 1)}
\text{\textbf{二阶：}}c(t) = K\left[\tau ^{2}\dfrac{d^{2}r(t)}{dt^{2}} + 2\zeta \tau \dfrac{dr(t)}{dt} + r(t)\right]
\Rightarrow G(s) = \color{#D63A2F}{K(\tau ^{2}s^{2} + 2\zeta \tau s + 1)}
特点：只有零点；输出反映输入的变化趋势（「超前」作用）。
理想微分：阶跃输入 → 输出为脉冲 Kδ(t)
6、延迟环节
c(t) = r(t - \tau )
G(s) = \dfrac{C(s)}{R(s)} = \color{#D63A2F}{e^{-\tau s}}
输出波形与输入完全相同，仅滞后一个时间 τ（如物料输送、信号传输延迟）。
输出 = 输入向右平移 τ
小结：比例 K、惯性 K/(Ts+1)、积分 K/s、振荡、微分、延迟 e^(−τs) —— 六个「积木」搭出任一线性定常系统。
