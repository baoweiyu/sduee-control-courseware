对电网络，可直接利用复阻抗求传递函数，跳过列写微分方程。
例2-6　求例2-1 RLC 串联电路的传递函数
①由微分方程 LC\cdot u_{o}'' + RC\cdot u_{o}' + u_{o} = u_{i} 零初始条件取拉氏变换：
　G(s) = \dfrac{U_{o}(s)}{U_{i}(s)} = \dfrac{1}{LCs^{2} + RCs + 1}
②复阻抗法验证：令 Z_{1} = R + Ls，Z_{2} = \dfrac{1}{Cs}（分压关系）
　G(s) = \dfrac{Z_{2}}{Z_{1} + Z_{2}} = \dfrac{1/(Cs)}{R + Ls + 1/(Cs)}
③G(s) = \dfrac{U_{o}(s)}{U_{i}(s)} = \dfrac{1}{LCs^{2} + RCs + 1}　两种方法结果一致
