五个环节的传递函数
运放Ⅰ比例
G_1(s) = \dfrac{U_1(s)}{U_e(s)} = -\dfrac{R_1}{R_0} = K_1,\quad U_e = U_r - U_f
运放ⅡPI 校正
G_2(s) = \dfrac{U_2(s)}{U_1(s)} = \dfrac{\tau s + 1}{Ts}
功放比例
G_3(s) = \dfrac{U_a(s)}{U_2(s)} = K_2
电动机双输入
m_c{=}0:\ G_u(s) = \dfrac{N(s)}{U_a(s)} = \dfrac{K_u}{T_aT_ms^2+T_ms+1}
u_a{=}0:\ G_m(s) = \dfrac{N(s)}{M_c(s)} = \dfrac{-K_m(T_as+1)}{T_aT_ms^2+T_ms+1}
测速机反馈
G_f(s) = \dfrac{U_f(s)}{N(s)} = K_f
综合：闭环传递函数（叠加原理）
m_{c}(t)=0 时（给定作用） \Phi_u(s) = \dfrac{N(s)}{U_r(s)} = \dfrac{K_0(\tau s+1)}{T_aT_mTs^3+T_mTs^2+(T+K_0K_f\tau)s+K_0K_f}
u_{r}(t)=0 时（扰动作用） \Phi_m(s) = \dfrac{N(s)}{M_c(s)} = \dfrac{-K_m(T_as+1)}{T_aT_mTs^3+T_mTs^2+(T+K_0K_f\tau)s+K_0K_f}
其中　K_0 = K_1K_2K_u（前向通道总增益）
💡
线性系统有两个输入（给定 u_{r} 与扰动 m_{c}）时，分别求各自的闭环传递函数再叠加；两者的分母完全相同——它就是闭环系统的特征多项式。
要点：电动机是"双输入"环节（给定 + 负载扰动）；给定通道与扰动通道的区别仅在分子，分母同为闭环特征多项式。
