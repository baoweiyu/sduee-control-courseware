💡 串联、并联、反馈——三种基本联接的多个环节，都可以合并为一个等效环节
串 联
首尾相接
G(s) = G_{1}(s)\cdot G_{2}(s)
n 个串联：G(s) = \prod G_{i}(s)
注意：环节间须无负载效应
并 联
同入相加
G(s) = G_{1}(s) + G_{2}(s)
n 个并联：G(s) = \sum G_{i}(s)
（各支路信号相加/减）
反 馈
闭环回路
\text{负反馈：}\Phi (s) = \dfrac{G(s)}{1+G(s)H(s)}
正反馈：分母为 1−G(s)H(s)
（先合并内环，再处理外环）
反馈联接的几个名词（负反馈）
偏差信号
E(s) = R(s) - B(s)（正反馈为 R+B）；H(s)=1 时称单位反馈
开环传递函数
G(s)H(s) = \dfrac{B(s)}{E(s)}；前向通道：G(s) = \dfrac{C(s)}{E(s)}
闭环传递函数推导
C = EG = (R-CH)G \Rightarrow \Phi (s) = \dfrac{C(s)}{R(s)} = \dfrac{G(s)}{1+G(s)H(s)}
