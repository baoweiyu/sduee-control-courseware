① R(s) 作用（令 N=0）
\Phi (s) = \dfrac{C(s)}{R(s)} = \dfrac{G_{1}G_{2}}{1+G_{1}G_{2}H}；　\Phi _{e}(s) = \dfrac{E(s)}{R(s)} = \dfrac{1}{1+G_{1}G_{2}H}
E(s)=R(s)−B(s)；H=1（单位反馈）时　Φe(s) = 1 − Φ(s)
② N(s) 作用（令 R=0，恒值系统）
\Phi _{n}(s) = \dfrac{C(s)}{N(s)} = \dfrac{G_{2}}{1+G_{1}G_{2}H}；　\Phi _{ne}(s) = \dfrac{E(s)}{N(s)} = \dfrac{-G_{2}H}{1+G_{1}G_{2}H}
此时 E(s) = 0 − B(s) = −H(s)C(s)
③ 两输入同时作用（叠加原理）
C(s) = \Phi (s)R(s) + \Phi _{n}(s)N(s)
= \dfrac{G_{1}G_{2}}{1+G_{1}G_{2}H}\cdot R(s) + \dfrac{G_{2}}{1+G_{1}G_{2}H}\cdot N(s)
📌
各传递函数的分母都相同：1 + G_{1}(s)G_{2}(s)H(s)
这就是闭环系统的特征多项式（与输入无关）。
