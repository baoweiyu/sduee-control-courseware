为什么引入信号流图？——方框图化简繁琐、费时、易出错。信号流图用图形表示线性代数方程组，与方框图对应，且可借助梅逊公式直接写出传递函数。
例：线性代数方程组及其"因果式"改写
\begin{cases} a x_0 - x_1 + b x_2 = 0\\[4px] c x_0 + d x_1 - x_2 = 0 \end{cases}
改写 (a)
\begin{cases} x_1 = a x_0 + b x_2\\[4px] x_2 = c x_0 + d x_1 \end{cases}
改写 (b)
\begin{cases} x_1 = -\dfrac{c}{d}\,x_0 + \dfrac{1}{d}\,x_2\\[8px] x_2 = -\dfrac{a}{b}\,x_0 + \dfrac{1}{b}\,x_1 \end{cases}
两种因果式 ⇒ 两张信号流图（不唯一！）
(a)　支路 a、b、c、d
(b)　支路 −c/d、1/d、−a/b、1/b
⚪
节点："○"表示变量（信号）
➡️
支路：连接节点的有向线段
✖️
支路传输：支路标注的数学关系（增益）
关键认知：信号流图表达的是"因果关系"——每个节点变量等于其入支路传输与对应变量乘积之和。同一方程组可有多种因果式，因此信号流图不唯一。
