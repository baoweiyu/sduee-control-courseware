主观题（5 分）：用梅逊公式求 G(s)=X₄/X₁——先自己数通道与回环
0 / 8
① 前向通道（2 条）
P_{1} = a\cdot e\cdot f
 P_{2} = a\cdot b\cdot c\cdot f
② 回环（3 个）
L_{1} = -d（自回环）　L_{2} = -eg
 L_{3} = -bcg
③ 互不接触与 \Delta _{k}
仅 L_{1}\cdot L_{2} 互不接触 ⇒ \sum L_{2} = deg
\Delta _{1} = 1+d（L_{1} 不接触 P_{1}）；\Delta _{2} = 1
✔ 结果
\dfrac{X_{4}}{X_{1}} = \dfrac{aef(1+d) + abcf}{1 + d + eg + bcg + deg}
