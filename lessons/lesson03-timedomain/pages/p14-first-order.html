实例 1：水箱液位系统
输入 qi(t)（进水流量增量）· 输出 h(t)（液位）
物料平衡：A\dfrac{\mathrm{d}h}{\mathrm{d}t} = q_i - \dfrac{h}{R}（R：液阻）
AR\dfrac{\mathrm{d}h}{\mathrm{d}t} + h = R\,q_i
一阶惯性环节，时间常数 T = AR
实例 2：RC 电路
输入 ui(t) · 输出 uC(t)（电容电压）
回路方程：Ri + u_C = u_i,\; i = C\dfrac{\mathrm{d}u_C}{\mathrm{d}t}
RC\dfrac{\mathrm{d}u_C}{\mathrm{d}t} + u_C = u_i
一阶惯性环节，时间常数 T = RC
归纳：一阶系统的通用数学模型
物理背景不同，动态结构相同——都可归纳为一阶微分方程：
T\,\dfrac{\mathrm{d}c(t)}{\mathrm{d}t} + c(t) = r(t)
闭环传递函数　\varPhi(s) = \dfrac{C(s)}{R(s)} = \dfrac{1}{Ts+1}
T —— 时间常数，是一阶系统唯一的特征参数。
