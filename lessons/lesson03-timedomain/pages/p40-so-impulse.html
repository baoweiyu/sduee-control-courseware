脉冲响应 = 阶跃响应的导数
由 k(t)=\dfrac{dh(t)}{dt}，对欠阻尼情形求导得
k(t)=\dfrac{\omega_{n}}{\sqrt{1-\zeta^{2}}}\,e^{-\zeta\omega_{n} t}\sin(\omega_{d} t)\quad(t\geq 0)
ζ ≥ 1 时同样有解析式，且 k(t) ≥ 0（不变号）。
① ζ ≥ 1：k(t) 不变号（阶跃响应单调的必然结果）；
② 0 < ζ < 1：k(t) 首次过零的时刻 恰好是 tp（极值点导数为零）；
③ 0 ~ tp 间 k(t) 与 t 轴围成的面积 = 1 + σ%（积分即 h(tp) − h(0)）。
欠阻尼脉冲响应（ζ=0.5，ωn=1，阴影面积=1+σ%）
联系脉冲响应把"微分—积分"关系变成可读图信息：k(t) 首次过零 → tp，首波面积 → 1+σ%。
