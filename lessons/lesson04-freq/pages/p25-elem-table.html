典型环节的 Nyquist 轨迹（红●=ω=0 起点，蓝线=ω 增大方向）
比例
G(s)=K
轨迹退化为正实轴上一点 K——与 ω 无关
积分
G(s)=\dfrac{1}{s}
沿负虚轴自 ∞ → 0，相角恒 −90°
微分
G(s)=s
沿正虚轴自 0 → ∞，相角恒 +90°
惯性
G(s)=\dfrac{1}{Ts+1}
下半圆：(1, j0) → 原点，相角 0 → −90°
一阶微分
G(s)=Ts+1
自 (1, j0) 沿正虚轴向上，相角 0 → +90°
振荡
G(s)=\dfrac{1}{T^{2}s^{2}+2\zeta Ts+1}
起于 (1, j0)，ζ<1/√2 时类圆回卷，相角 0 → −180°
二阶微分
G(s)=T^{2}s^{2}+2\zeta Ts+1
振荡的上半平面镜像，相角 0 → +180°
延迟
G(s)=e^{-T_{D}s}
单位圆顺时针无限绕行，相角 −ωTD 无界
记忆抓住起点、终点、所在象限三件事：积分↔微分、惯性↔一阶微分、振荡↔二阶微分互为倒数（幅值互换、相角反号）；比例与延迟没有倒数配对。
