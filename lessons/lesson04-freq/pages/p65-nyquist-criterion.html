Z = P - N
P = 开环右半平面极点数（已知）；N = 全频段 Nyquist 曲线逆时针包围 (−1, j0) 的圈数；Z = 闭环右半平面极点数。Z = 0 ⇔ 闭环稳定。
稳定：N = P
P=0 时曲线不包围 (−1, j0)（N=0）⇒ Z = P − N = 0，闭环稳定。
不稳定：N ≠ P
P=0，曲线顺时针包围 (−1, j0) 一圈（N=−1）⇒ Z = P − N = 1，闭环不稳定。
边界：曲线穿过 (−1, j0)
P=0，曲线恰好通过 (−1, j0) ⇒ 存在闭环虚轴特征根，处于稳定边界，需进一步检查（如虚轴根的重数），不能直接按普通计数式判稳。
数 N 要领先补 ω<0 镜像、必要时补 ν×180° 顺时针 ∞ 圆弧，再沿曲线数绕 (−1, j0) 的净圈数（逆时针为正）。流程：画曲线 → 数 N → 查 P → 算 Z=P−N → 判稳。
