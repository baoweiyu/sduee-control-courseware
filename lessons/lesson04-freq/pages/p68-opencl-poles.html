推导链：F(s) = 1 + G(s)H(s) 的零极点
把 G(s)、H(s) 各自写成分式（N、D 均为 s 的多项式）
G(s)=\dfrac{N_{G}(s)}{D_{G}(s)}\qquad H(s)=\dfrac{N_{H}(s)}{D_{H}(s)}
开环 G(s)H(s)=\dfrac{N_{G}(s)N_{H}(s)}{D_{G}(s)D_{H}(s)}　⇒　开环极点：DG(s)·DH(s) = 0 的根
↓ 闭环 Φ(s) = G/(1+GH)，分子分母同乘 DGDH
\Phi(s)=\dfrac{G(s)}{1+G(s)H(s)}=\dfrac{N_{G}(s)D_{H}(s)}{D_{G}(s)D_{H}(s)+N_{G}(s)N_{H}(s)}
闭环特征方程：DGDH + NGNH = 0　⇒　它的根 = 闭环极点
↓ 辅助函数 F(s) = 1 + GH 通分，与上面对照
F(s) 的分子、分母正好各管一件事
F(s)=1+G(s)H(s)=\dfrac{D_{G}(s)D_{H}(s)+N_{G}(s)N_{H}(s)}{D_{G}(s)D_{H}(s)}
F(s) 的零点（分子 DGDH+NGNH = 0）—— 正是闭环特征根（闭环极点）；
F(s) 的极点（分母 DGDH = 0）—— 正是开环极点。
Z、P、N 三个量的角色
量含义来源
Z右半 s 平面 F(s) 零点数 = 右半闭环极点数待判定——稳定要求 Z=0
P右半 s 平面 F(s) 极点数 = 右半开环极点数已知——开环传递函数直接读出
NГ 曲线包围原点的圈数 = GH 曲线包围 (−1, j0) 的圈数图上数出（逆时针为正）
映射原理落到此处：Z=P-N。闭环极点难求 ⇒ 转化为"已知 P、图上数 N"——这就是 Nyquist 图解判稳的全部逻辑。
承上启下F(s)=1+GH 把闭环极点与开环零极点连在一起：F 平面的原点对应 GH 平面的 (−1, j0) 点——下一页正式搬到 G(s)H(s) 平面。
