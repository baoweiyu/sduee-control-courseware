无源滞后网络（RC 电路）
R_{1} 串联在上臂，R_{2} 与 C 串联作输出臂；输出 u_{c} 取自 R_{2}+C 两端。
由阻抗分压求传递函数
① 输出臂复阻抗 Z_{2}=R_{2}+\dfrac{1}{Cs}=\dfrac{R_{2}Cs+1}{Cs}，串联臂 Z_{1}=R_{1}
分压 G_{c}(s)=\dfrac{U_{c}(s)}{U_{r}(s)}=\dfrac{Z_{2}}{Z_{1}+Z_{2}}=\dfrac{R_{2}Cs+1}{(R_{1}+R_{2})Cs+1}=\dfrac{Ts+1}{\beta Ts+1}
其中 \beta=\dfrac{R_{1}+R_{2}}{R_{2}}>1,\qquad T=R_{2}C
与超前网络对照
超前（α<1）零点 \frac{1}{T} 在前、极点 \frac{1}{\alpha T} 在后 → 相位超前；低频增益衰减，需放大器补偿。
滞后（β>1）极点 \frac{1}{\beta T} 在前、零点 \frac{1}{T} 在后 → 相位滞后；低频增益为 1，无需补偿。
滞后网络的价值不在相角，而在高频段幅值衰减 −20lgβ（下一页）。
要点滞后网络 G_{c}(s)=\dfrac{Ts+1}{\beta Ts+1}（\beta>1，T=R_{2}C）：低频 0 dB 不衰减，高频被压到 -20\lg\beta。
