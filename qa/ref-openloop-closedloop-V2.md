1. 拆解开环与闭环的分式假设 $G(s)$ 和 $H(s)$ 各自都是复杂的分式：$G(s) = \frac{N_G(s)}{D_G(s)}$  （$N_G$ 是分子，$D_G$ 是分母）$H(s) = \frac{N_H(s)}{D_H(s)}$那么，开环传递函数是它们的乘积：$$G(s)H(s) = \frac{N_G(s)N_H(s)}{D_G(s)D_H(s)}$$注意：让开环分母 $D_G(s)D_H(s) = 0$ 的根，就是开环极点。现在，我们来写出闭环传递函数 $\Phi(s) = \frac{G(s)}{1+G(s)H(s)}$，并把上面的分式代进去：$$\Phi(s) = \frac{\frac{N_G}{D_G}}{1 + \frac{N_G N_H}{D_G D_H}}$$为了化简这个繁分数，我们将分子和分母同时乘以 $D_G D_H$，得到：$$\Phi(s) = \frac{N_G D_H}{D_G D_H + N_G N_H}$$盯住这个化简后的闭环分母！闭环系统的特征方程是：$D_G D_H + N_G N_H = 0$。让这个方程成立的根，就是决定系统生死的闭环极点。如果这里面有正实部的根，闭环系统就炸了。2. 揭秘辅助函数 $F(s) = 1+GH$现在，我们来看看数学家生造出来的那个“双重间谍”函数 $F(s)$ 到底长什么样：$$F(s) = 1 + G(s)H(s)$$把分式代入并通分：$$F(s) = 1 + \frac{N_G N_H}{D_G D_H} = \mathbf{\frac{D_G D_H + N_G N_H}{D_G D_H}}$$3. 见证奇迹的对比现在，请把 $F(s)$ 的分子分母，和我们刚才推导的开环、闭环极点做个对比：$F(s)$ 的分子是 $D_G D_H + N_G N_H$。这不就是刚才那个决定生死的闭环特征方程吗！所以，$F(s)$ 分子为 0 的点（即 $F(s)$ 的零点 $Z$），就是闭环极点。$F(s)$ 的分母是 $D_G D_H$。这不就是开环传递函数的分母吗！所以，$F(s)$ 分母为 0 的点（即 $F(s)$ 的极点 $P$），就是开环极点。
