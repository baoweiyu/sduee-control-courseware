# 奈奎斯特判据核心推导：辅助函数 F(s) 的零极点映射关系

在奈奎斯特稳定判据中，判定闭环系统稳定性的核心在于构造辅助函数 $F(s) = 1 + G(s)H(s)$。以下为其零极点与系统开/闭环极点等价关系的严格数学证明。

## 1. 定义开环传递函数
设系统的开环传递函数为两个多项式之比：
$$G(s)H(s) = \frac{N(s)}{D(s)}$$
*   **开环极点：** 使分母 $D(s) = 0$ 的根。

## 2. 闭环特征方程推导
闭环系统的传递函数表达式为：
$$\Phi(s) = \frac{G(s)}{1 + G(s)H(s)}$$
将开环传递函数代入并化简（假设 $G(s) = \frac{N_G(s)}{D_G(s)}$，$H(s) = \frac{N_H(s)}{D_H(s)}$，则 $N(s)=N_G(s)N_H(s)$，$D(s)=D_G(s)D_H(s)$）：
$$\Phi(s) = \frac{N_G(s)D_H(s)}{D(s) + N(s)}$$
*   **闭环特征方程：** $D(s) + N(s) = 0$
*   **闭环极点：** 使 $D(s) + N(s) = 0$ 的根（决定闭环系统的绝对稳定性）。

## 3. 构造辅助函数 $F(s)$ 并通分
对辅助函数 $F(s) = 1 + G(s)H(s)$ 进行通分：
$$F(s) = 1 + \frac{N(s)}{D(s)} = \frac{D(s) + N(s)}{D(s)}$$

## 4. 核心数学等价结论
对比辅助函数 $F(s)$ 与开/闭环特征多项式，可得出以下严格映射关系：

1.  **$F(s)$ 的分子多项式恰为闭环特征多项式。** 
    *   因此，$F(s)$ 的**零点** 严格对应 **闭环极点**。
    *   若闭环系统不稳定（存在正实部闭环极点），在数学上等价于 **$F(s)$ 在右半平面存在零点**。
2.  **$F(s)$ 的分母多项式恰为开环特征多项式。**
    *   因此，$F(s)$ 的**极点** 严格对应 **开环极点**。

**教学小结：**
在应用柯西幅角原理 $N = Z - P$ 考查 $F(s)$ 的映射路径时：
*   **$Z$ (目标未知量)：** 闭环系统在右半平面的极点数（即 $F(s)$ 在右半平面的零点数）。为保证闭环稳定，必须满足 $Z = 0$。
*   **$P$ (已知条件)：** 开环系统在右半平面的极点数（即 $F(s)$ 在右半平面的极点数）。
*   **$N$ (几何观测值)：** $F(s)$ 映射曲线顺时针包围原点 $(0,0)$ 的圈数（等价于 $G(s)H(s)$ 曲线包围 $(-1, j0)$ 的圈数）。
