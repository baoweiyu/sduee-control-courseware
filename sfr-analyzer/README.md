# SFR Lab · 系统频率响应分析工具

基于经典低阶 SFR 模型的纯静态交互分析工具。完成物理参数扫描、T₁ 专项扫描、三种 λ 变化路径、闭环零极点轨迹、负荷阶跃频率响应曲线簇和动态指标联动分析。

## 快速使用

在本仓库根目录运行：

```bash
npm run dev
```

打开 `http://localhost:7100/`，服务器会进入本工具。原有课件仍可通过 `/player/index.html` 访问。

也可以将本目录完整上传到 GitHub Pages、Cloudflare Pages 或任意静态网站托管服务，入口为 `index.html`。页面不需要后端、不访问外部 CDN，常规计算全部在浏览器内完成。

## 操作步骤

1. 在左侧输入 H、D、K_F、T_R、F_H 的初始值和允许最小值、最大值。
2. 选择物理参数、T₁ 或 λ 扫描，并选择对应变化路径。
3. 设置扫描上下限，点击“应用扫描范围”。页面会显示扫描区间与物理参数允许范围的交集，无效采样自动排除。
4. 点击左侧极点轨迹，或拖动双图上方滑块，选择工况。也可以直接在数值框输入任意扫描值。
5. 使用“设为基准”固定当前完整场景，再移动滑块进行比较；“恢复基准”可恢复保存时的场景与工况。
6. 右图可切换实际频率和归一化频差，显示最低点、准稳态参考线及 2% 整定带。
7. 使用顶部或底部按钮导出配置、响应 CSV、完整 JSON 和双图 PNG。

### 图形操作

- 左图单击轨迹：选择最近的扫描工况；重合位置出现候选工况选择框。
- 左图拖框：局部放大；双击或点击“复位”：恢复自动视图。
- “坐标”面板：手动设置实轴、虚轴范围；可切换实虚轴等比例。
- 滑块方向键：以扫描跨度的 1/1000 微调；Shift + 方向键：以 1/100 步进。
- 右图取消“自动时间轴”后可手动设置显示时间上限。

## 模型与符号约定

```text
Gp(s) = 1/(2Hs + D)
Gf(s) = K_F(1 + F_H T_R s)/(1 + T_R s)
Gd(s) = (1 + T_R s) /
        [2H T_R s² + (2H + (D + K_F F_H)T_R)s + D + K_F]
```

- 功率和频率偏差采用标幺值；正负荷阶跃 ΔP > 0 对应负频率偏差。
- 实际频率为 `f(t) = f₀ + Δf(t)`。
- 归一化频差为 `Δf(t)/Δf∞`，从 0 趋近 1。
- 超调量按完整有零点传递函数的实际响应计算，不使用无零点二阶近似公式。
- F_H = 1 时自动约简为一阶模型，相消零极点不再作为实际动态模态。
- D = 0 时 T₁、K₁、k 显示为“—”，仍按未归一化物理模型计算。
- 若仿真结束时响应尚未保持在 2% 整定带内，整定时间显示为超出仿真时长并给出提示。

## 独立验证

数值验证要求 Python、NumPy 和 Node.js：

```bash
python validate.py
```

Python 独立使用 `numpy.roots` 求根，并对状态方程进行 20000 步 RK4 积分；随后调用网页实际 `core.js`，核对参数路径、零极点、自然频率、阻尼比、响应采样、最低频率、超调量、整定时间、准稳态频差和初始 RoCoF。

浏览器验收要求本机安装 Chrome 或 Edge：

```bash
node browser_test.js
```

该程序临时启动静态服务器和无头浏览器，检查扫描、滑块、轨迹点选、极零相消、基准比较和三种文件的实际下载，结束后自动关闭测试进程。

## 模型适用范围

本工具面向单区域低阶线性 SFR 模型，不包含调速器死区、限幅、备用约束、多区域联络线及其他高阶动态。工程正常范围不由程序预设，完全采用用户输入的允许范围；程序只执行必要的数学合法性检查。
