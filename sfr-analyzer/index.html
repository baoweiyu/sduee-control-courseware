计算说明与模型适用范围

数值方法

直接由完整闭环传递函数求根，并以部分分式解析式计算阶跃响应。欠阻尼、临界阻尼和过阻尼分别处理；滑块处于未采样位置时实时精确重算。

特殊工况

FH = 1 时自动约简为一阶模型，不把相消零极点当作实际模态。D = 0 时 T₁、K₁、k 显示为“—”，仍使用物理模型计算。

符号约定

功率与频率均采用标幺值。正负荷阶跃 ΔP > 0 产生负频率偏差；归一化频差定义为 Δf(t)/Δf∞，因此由 0 趋近 1。

适用范围

单区域低阶 SFR 线性模型，不包含调速器死区、限幅、备用约束及多区域联络线动态。工程允许范围完全由左侧用户输入约束。
