一、播放器 / 导航（红线，犯过的绝不再犯）
═══════════════════════════════════════════
1. 导航栏不得中途消失；任何情况下 ←/→ 与 Space 键盘翻页必须有效（曾出现导航消失后无法翻页）。
2. 导航模式：缩略图若无法生成，改为大页码 + 内容关键词，禁止空白缩略图；可跳转、可返回当前页。
3. 导航条中不显示"验收模式"等内部字样。
4. 任何页面不得出现 JS 卡死导致整个播放器无法继续（曾发生在第二章 P44，多因脚本错误/死循环）。
5. 播放器键盘处理用 e.code（不是 e.key）；自动化测试派发 KeyboardEvent 时必须带 code 属性。
6. InAppBrowser 的真实输入（send_keys/mouse_click/screenshot）要求面板可见；面板不可见时改用
   evaluate 在页面内派发 DOM 事件或读取 DOM 状态做验证。

二、公式
═══════════════════════════════════════════
7. 所有公式统一 MathJax + STIX2/XITS 风格字体（用户明确认可的最终效果），不得混用浏览器默认
   衬线数学字体；新增页面必须复用 theme/mathjax 三行脚本引用。
8. 公式不得渲染错位、乱版（"例："后面的公式曾整体乱掉）；大括号、分段函数必须正常显示
   （第二章 P39 大括号曾缺失）。
9. 稳态解/暂态解等标注必须与对应公式上下对正，不得错位。
10. 短词不得不正常换行（"完成"两字换行、"写成因果式"换行；用 white-space:nowrap 保护）。
11. 修改公式相关文件后必须重新截图验证，不得凭源码想象效果。
12. 【技术坑】Python 脚本里写含 LaTeX 的内容必须用原始字符串 r"..."，否则 \t 会变成 Tab、
    公式静默损坏。

三、图（方框图 / 坐标图 / 流程图 / s 平面图）
═══════════════════════════════════════════
13. 相加点统一：圆圈内一个 × 叉，外部标注 +/-；禁止圆圈套圆圈、禁止圆圈内再画 + − 号。
14. 图内任何文字标注不得与线条重叠（含坐标轴、信号线、框边）；反馈线止于相加点圆周，
    不得画进圆内。
15. 坐标轴必须带箭头；同一页多个图必须对齐（不得一偏上一偏下）。
16. 图线必须横平竖直：方框图信号线用正交折线（先横后竖），不得斜线（第一章并联支路曾画斜线）。
17. 阶跃时刻 r(t) 与 c(t) 的 t=0 位置必须对齐。
18. 图中符号标注左右/两边必须对齐（如 Gs 两侧标注）。
19. 图不得"随手画"：曲线形状要符合数学意义（超调、振荡、包络线、可行域阴影必须几何正确——
    第三章 p81 可行区域阴影要与"楔形∩圆外∩垂线左"的交集一致，不能简单画矩形带）。
20. 图内元素不得超出图框边界；文字不得被遮挡；图不得过挤、字号不得过小。
21. 箭头与方框不得重叠，连线要有足够长度的直线段，不能只剩箭头。
22. 图中禁止出现"程序重绘"等制作痕迹字样；重复标题删除（页面顶部已有章节标题时图内不再重复）。
23. 框图过高会把下方文字挤出/截断：先算总高再定 viewBox，必要时压缩上部空白通道
    （第一章 p24 教训：扰动改为竖直向下直入被控对象、前馈支路水平左行再竖直下入相加点，
    图高 520→372，下方说明卡才完整）。
24. 同一页并排示意图（如开环/闭环/复合）高度必须一致，下方定义、优缺点才能对齐。
25. 长公式/长传递函数框不得被页面底部遮挡；信息太多时分两图或分步显示，不硬挤。
26. 经典结构图重绘参考（已获用户认可）：
    - 复合控制按扰动补偿：扰动竖直向下入被控对象 + 分支水平往左入前馈控制器 +
      前馈输出竖直向下入相加点（− 号标在相加点入口旁）。

五、分步动画 / 交互动效（用户最看重的加分项）
═══════════════════════════════════════════
31. 通用原则：分步揭示用 [data-step] + ACT.step；页面步数与播放器联动。
32. 闪烁/高亮只保留"当前步"：历史步骤保持显示但静止——用 g.flash（当前步）而不是
    g.shown 累积加动画（第一章 p30 教训：7 个高亮圈齐闪会乱掉）。
    标准做法：包装 S.next/S.reset，每次先移除全部 .flash 再给最后一个 .shown 组加 .flash。
33. 步进函数的 paint()/render() 必须先清除旧状态类再按当前步重绘，否则 reset 失效
    （第三章 p53 教训：只加不移除导致重置后高亮残留）。
34. 用户认可的动画模板，新交互优先仿造：
    - 第二章 p47 梅逊公式实验台（逐步高亮回环/通道、淡化无关部分、字幕条+计数器）——
      第三章 p53 劳斯表逐步演示即仿此模板，验证成功；
    - 第三章 p16 一阶系统滑块实验、p34 二阶 ζ/ωn 联动实验（滑块改参数，曲线+指标+极点同变）；
    - 介绍前向通道/互不接触回路时，其余部分必须淡化处理，当前对象用唯一醒目色。
35. act-note 结论条单行容量约 47 字（fs26）；超长就缩短文本或页内加
    .act-note{font-size:23px}，禁止换行溢出。
36. 分步动画 QA 用 qa/shot-k.html?page=<路径>&k=N 截中间态（k=0 初始态）；
    普通 shot.html 会自动推进到最终态，看不到中间步骤。

十四、第四章施工新增教训（2026-09-07，87 页修改后沉淀）
═══════════════════════════════════════════
68. 【重大技术坑】SVG 帮助函数 mk()/tx() 必须带 parent 参数并兜底：
    const mk = (tag, attrs, parent) => { ...; (parent || svg).appendChild(n); return n; };
    若只收 2 参而调用处传了第 3 参（父 g 组），参数被静默丢弃——marker 的 path 会被挂到
    SVG 根节点 (0,0) 处形成左上角小三角残影，且 <marker> 为空、全页坐标轴/曲线箭头
    全部消失。第四章 24 页集体中招（复制模板时引入的变体）。
    新页面模板强制检查；排查命令：
    grep -n 'const mk = (tag, attrs) =>' lessons/lesson0X/pages/*.html
    （三参变体 mk(svg,tag,attrs) 同样要补第 4 参 parent）。
69. x 轴轴名（ω / ωc / t / φ）贴右边缘、压箭头尖是高频问题：完稿前检查
    viewBox 宽 − (x1 + 标签起点 + 标签宽) ≥ 8px；不够就收 x1，或把标签放到
    箭头尖下方 / 轴线上方（如 tx(x1, y0+30, "ω", an:"end")）。本轮修 6 处。
70. 相频图方向：0° 必须在上、向下为负（−90°/−180°/−270° 依次向下）；
    幅频/相频数据不得用 Math.max/min 钳位到量程内——会造出假的"平尾"，
    量程要包住真实数据（p86 曾上下颠倒 + 钳位平尾，整图不可信）。
71. 文字标注 halo（paint-order:stroke;stroke:#FFF;stroke-width:5）只有
    把该文字【最后绘制】才真正切断线条；先画文字后画线，线照样压字。
    (−1,j0) 附近、0dB 线与 −180° 线附近是"多线包抄区"，固定标签一律 halo+最后画，
    不要费劲找绝对空白。
72. 每幅动图配独立播放按钮，禁止自动播放：.hd 行 flex 两端布局 + .pbtn/.pbtn.ghost
    样式 + playToken 递增防竞态（旧动画未播完又点按钮时直接失效旧帧循环）。
73. 互动题门控标准模式（第四章 p86 验证）：选项区三段式不变；左图答案标注组
    初始 opacity=0，由包装后的 ACT.step 在 S.cur>=1 时淡入；解析条 data-step="2"。
    这样"先展示全部选项 → 再揭答案 → 图上标注同步出现"一步到位。
74. 第四章用户认可的新动画模板，后续章节优先仿造：
    - s 域→F(s) 域映射联动（p56-60 区间 6 页）：左右双坐标系，左边动点沿围线走、
      右边像轨迹以正确速度同步走，两域曲线用同色系区分来源，逐步拆分——
      用户原话"左边转圈，右边也用正确的速度转圈，学生才可以直观理解"；
    - 典型环节极坐标图逐点绘制（p16 等）：ω 从 0→∞ 逐点描出，体现"有方向的线"；

    - 等 M 圆滑块实验（p77）：滑块拖圆，实时判"相切/相交/相离"并给出 Mr 读数。
