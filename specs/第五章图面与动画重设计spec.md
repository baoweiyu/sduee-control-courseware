# 第五章《根轨迹法》图面与动画重设计 Spec

**版本：** RDS-1.0（2026-09-13）  
**适用范围：** `lessons/lesson05-root-locus/` 全部根轨迹图；不修改本文件之外的生产文件。  
**依据：** 第五章逐页 spec、R1-R10、制作规范第 12-30、68-73、81-84、93-111、121-126 条及现有页面内容。

## 0. 重设计目标

当前图面不得继续采用“细线 + 小标记 + 大片空白 + 只有一条轨迹”的默认图表样式。重设计后的每幅图必须同时承担：

1. 让学生一眼看出零极点、实轴段、分支方向和稳定边界；
2. 让关键数值（分离点、虚轴交点、K）成为图内可读证据；
3. 让动画表达“参数增加导致闭环极点运动”，而不是只显示一条逐渐变长的线；
4. 让图占据卡片主要面积，文字只解释图上正在发生的事情。

不得凭空增加教材没有的结论；新增底纹、徽章、拖尾均服务于已有的根轨迹绘制法则和例题数值。

## 1. 全章统一视觉语言

### 1.1 图面尺寸与构图

- 普通单图 SVG 设计尺寸统一 `viewBox 0 0 960 600`；双图每幅 `760×520`；三小图每幅 `540×300`。执行方不得用 CSS 拉伸改变数学比例。
- 图在卡片内占可用高度 **78%~88%**、宽度 **92%~96%**；图卡内边距 16~24px，图与卡片标题间 10~14px。
- 坐标绘图区占 SVG 的 86% 以上；右上角放图例，左上角放“本图要回答的问题”短标签，底部只放 σ 刻度和必要的 K 徽章。
- 轨迹密集时优先扩大图，不缩小字号；文本转移到右侧说明卡，不在图内写段落。
- 同一例题跨页的 `xlim/ylim` 必须保持一致；若要放大关键区域，必须另加局部 inset，不能改变主图坐标口径。

### 1.2 线宽体系（设计像素）

| 元素 | 线宽 | 说明 |
|---|---:|---|
| 坐标轴 | 2.2px | 带箭头，深灰蓝 |
| 主根轨迹 | 5.0px | 圆角端帽，颜色按分支 |
| 实轴根轨迹段 | 7.0px | 主轨迹同色，透明度 1 |
| 预览底轨 | 2.2px | 浅蓝 `#C9D6F2`，动画时恒显 |
| 渐近线 | 2.4px | 橙灰 `#F5821F`，`dash 8 6` |
| ζ 射线 | 2.4px | 深棕灰 `#7A4E2D`，`dash 3 5` |
| 引导线/引线 | 1.8px | 灰蓝，避免抢主轨迹 |
| 关键点连接线 | 2.0px | 对应关键点颜色 |
| 箭头三角 | 外接 18×14px | 与轨迹同色、白描边 1px |

### 1.3 零极点与关键标记

- 极点：深蓝 `#16324F` 的粗 `×`，外接 24×24px，线宽 4px。
- 零点：深蓝空心圆，直径 24px，线宽 4px，白色填充。
- 重合极点/零点：采用“外环 + 中心十字”复合符号，并旁注“重合”；不得把多个符号糊成一个点。
- 分离/会合点：实心圆徽标，直径 16px；外圈 28px 半透明光晕；引线指向右上或左下空白区；标签必须含 `d=…` 与 `K₁=…`。
- 虚轴交点：空心方块 18×18px，线宽 3px；上下点均绘制；统一单标签 `±jω, K₁=…`。
- 轨迹运动端点：12px 实心圆，外加 2~3 个透明度递减的拖尾圆点；拖尾只在动画层出现。

### 1.4 标注层级与字号

- 主标注：关键结论、`±jω`、`d/K₁`、例题当前 K；设计字号 26~30px，粗体，白 halo。
- 次标注：极点/零点名称、渐近线角、ζ、分支说明；24px，半粗，白 halo。
- 刻度：20~22px；轴名 28px；不得低于屏上 17px。
- 图例：22px，放右上角，不覆盖轨迹；图例项必须显示“颜色短线 + 中文/数学名称”。
- 下标统一使用 `tx(parent,x,y,"K_{1}=…")` 或 MathJax foreignObject，禁止平写 `K1`、`sigma_a`。
- 文字最后绘制；所有关键文字带 `paint-order:stroke` 白 halo；不得让线穿过字。

### 1.5 配色与语义

遵循规范第 102 条及 R4：主深蓝 `#1D3FA0`，次蓝 `#2B5CE6`，红 `#D63A2F` 只表示当前焦点/错误/终点，橙 `#F5821F` 表示渐近线/转角，灰蓝 `#5B6B8C/#8A97B5` 表示轴和次要元素，浅蓝 `#C9D6F2` 表示底轨。

- 共轭分支必须同色；由 data.pairs 决定，不按数组序号猜配对。
- 轨迹颜色不得与极点/零点颜色相同。
- 红色只在当前动画状态、稳定边界、警示或结论中使用，不把整张主轨迹全部涂红。

### 1.6 网格、底纹与引导元素

- 默认不画满屏网格；只画低透明度（≤10%）的主刻度垂线/水平线。
- 实轴根轨迹段下方可加浅蓝透明带，高度 16~22px，用来强调“该段满足相角条件”。
- 稳定区域底纹仅在讲稳定性的页面出现：左半平面浅蓝 `rgba(201,214,242,.18)`，右半平面不填色；虚轴用 3px 灰蓝线和“稳定边界”徽章。
- 渐近线交点用 36px 半透明圆环；渐近线角度用弧线 + `φ=…` 标签，不用孤立文字。
- 不得使用渐变、阴影堆叠、彩色背景大块遮挡轨迹。

## 2. fig.js 一次性新增能力

以下能力须在 `lessons/lesson05-root-locus/fig.js` 一次实现，全章页面只传数据和配置，不在各页重复写几何算法。

### 2.1 折线、区域与标记

```js
clipPolyline(pts, rect) -> Array<Array<[x,y]>>
fillRegion(parent, polygon, opt={fill, opacity, stroke, dash}) -> SVGElement
makeBadge(parent, x, y, text, opt={kind:"key", fs:24, fill, anchor, halo:true}) -> SVGElement
makePointBadge(parent, x, y, opt={shape:"circle", size:16, color, glow:true, label, sublabel}) -> SVGElement
makeKBadge(parent, x, y, K, opt={prefix:"K₁=", color:"#D63A2F", fs:24}) -> SVGElement
makeAngleArc(parent, cx, cy, r, a0, a1, opt={color, label, fs:22}) -> SVGElement
```

- `fillRegion` 的 polygon 必须在坐标变换后裁剪；不能用 CSS 伪造数学区域。
- `makeBadge` 只接受短文本（建议不超过 18 个汉字或一行公式）。
- `makeKBadge` 标签必须来自数据对象的 K，不接受页面硬编码的另一数值。
- `makeAngleArc` 角度使用数学坐标弧度，屏幕 Y 方向由库统一转换。

### 2.2 动画能力

```js
makeTrail(parent, pts, k, opt={color, radius:12, count:3, decay:.45}) -> SVGElement
makeMovingPoint(parent, pt, opt={color, radius:12, label, halo:true}) -> SVGElement
makeProgressTrack(parent, x, y, w, value, opt={min,max,label}) -> SVGElement
makeLegend(parent, items, opt={x,y,cols:1}) -> SVGElement
wire(total, paint, opt={dur:9000, onStep, labels})
```

每次 `paint(step)` 必须先清空动态层，再同时重绘：轨迹可见段、端点、拖尾、K 徽章、当前说明卡状态和图例焦点。不得让历史帧叠加。

### 2.3 figure 配置约定

```js
RL.figure("fig", "ex52", {
  xlim, ylim, static:false,
  regions:[{type:"stable", side:"left"}],
  guide:{asymArc:true, sigma:true, zeta:true},
  badges:{breakaway:true, crossing:true, k:true},
  endpoint:{point:true, trail:true},
  legend:[{color:"#2563EB", text:"分支 1"}],
  question:"K 增大时闭环极点如何运动？"
});
```

静态页 `static:true` 仍必须绘制完整图例、关键点徽标和必要的 K 标签；动画页则把上述元素按步序显示。

## 5. 验收标准

### 静态可测标准

- 每幅根轨迹主图主轨迹线宽 ≥5px，极点/零点标记外接尺寸 ≥24px；
- 图卡有效高度占 78%~88%，图形不得只占卡片上半部；
- 主标注 ≥26px、次标注 ≥24px、刻度 ≥20px；按屏上有效字号复算后不得低于规范底线；
- 每幅图至少具备：坐标轴箭头、零极点标记、分支方向箭头、图例或文字说明、必要关键点徽标；
- 有关键点的数据图必须显示 K；有虚轴交点必须同时显示上下方块和单一 `±jω,K₁` 标签；
- 数学单位等比误差≤1%；圆轨迹圆度误差≤2%；
- 图框外元素为 0；标签与曲线/轴/标签重叠为 0；
- 图卡覆盖率（非背景、非空白区域占可用图卡区域）≥60%，目标 65%~80%；
- 截图在 50% 缩放下仍能读出主标注和关键 K 值。

### 动画可测标准

- 从第 0 步开始，连续按下一步可到终态；连续按上一步可回到第 0 步；无死锁、无残留帧；
- reset 后动态层仅保留规定底轨和静态标记；`.flash` 最多一个当前对象；
- 每步至少有一个可观察变化：线、点、徽章、读数或说明卡；
- 终态曲线与静态数据完全重合，端点与数据数组最后点误差≤1 设计像素；
- 播放、重置、step、prev 后不得出现重复标签或 SVG 元素累积；
- 重点页 P6/P19/P30/P37/P42/P47/P52/P64/P66 逐页保存 0/中间/终态截图并核验。
