## 第一部分 全局整改规范

### 1. 动画标准

#### 1.1 强制范围

1. 凡页面中出现完整或局部根轨迹、实轴根轨迹段、渐近线示例、根轨迹族、180°/0°根轨迹对照，均视为“根轨迹图”，必须具备独立的“播放 + 重置”控制，并接入播放器上一步/下一步。当前源码已有根轨迹的页面至少包括 P6、P15-P19、P21、P28-P30、P32-P37、P39-P42、P46-P48、P51-P52、P54-P55、P59、P63、P66-P67；本合同还要求 P7、P53 增设教学所需的根轨迹动画。最终按整改后实际根轨迹图逐幅登记并以 100% 覆盖验收，不以当前页数或图数封顶。
2. 同页多幅根轨迹：每幅图有独立播放按钮；若教学语义是同步比较（P48、P52、P54、P66、P67），允许设置一个“同步播放”主按钮，但每幅图仍须可独立重置，且同一进度参数同时驱动所有对照图。
3. P64 虽为时间响应而非根轨迹，保留同步生长动画、播放、重置和步进；它不计入“根轨迹图动画覆盖率”。
4. 豁免仅限：P1/P2/P31/P43/P56 封面；P3 工程场景图；P4/P57/P63 中不表达根轨迹的控制框图；纯公式、表格、概念、互动页中的非轨迹装饰图。豁免理由必须是“该图不表示闭环极点随参数变化的轨迹”，不得以页面拥挤、开发时间或已有静态图为由豁免。

#### 1.2 每幅根轨迹动画的组成

- **播放按钮：** 图头右侧放标准图标按钮，文案可为“播放”；禁止加载即自动播放。每幅图独立按钮，防重复点击竞态。
- **K/参数联动：** `RL.figure(...).setProgress(f)` 驱动分支由开环极点向零点/无穷远生长；同步显示当前 `K₁`。参量根轨迹显示 `a`，P48 显示 `a/K₁` 两级参数，P66 显示 `b` 与渐近线交点。进度按规范使用对数 K 映射，不得用均匀几何进度冒充均匀 K。
- **重置：** 重置后回到第 0 步，只保留坐标系和必要题设；轨迹、运动端点、关键点说明和当前步高亮全部清除，不残留标签。
- **步进接入：** 用 `RL.wire(total, paint)` 接入 `ACT.step`，并提供 `window.prev`；空格、方向键、PgUp/PgDn 可前进/后退。纯状态机页用隐藏 `data-step` 撑足步数，防止按键直接翻页。
- **运动语义：** 淡蓝 `#C9D6F2` 可作完整预轨迹底轨；亮轨迹必须从极点生长，端点与路径取同一采样索引；端点箭头沿切向指向 K 增大方向。动画中关键点到达前不得提前显示最终 K 标注。
- **状态联动：** 当前轨迹、K 读数、说明卡边框和焦点文字使用同一状态色；历史步骤保留但静止、降权，只有当前步骤可闪烁。

#### 1.3 推荐步序与时长

通用 6 步：①题设、坐标轴与开环零极点；②判定并点亮实轴段；③显示渐近线/出射角等辅助构造；④分支从极点生长至首个关键点并停顿；⑤继续通过分离/会合点或虚轴交点，弹出坐标与 K；⑥生长至有限零点/画面边界，补齐方向箭头和结论。

- 简单二阶图：4-6 步，自动播放 8 秒。
- 三/四阶综合图：6-10 步，自动播放 10-12 秒。
- 双图同步或参数变形：5-8 步，自动播放 10-15 秒。
- 每个教学停顿 0.6-1.2 秒；关键点停顿不少于 1 秒；动画全过程参数单调，不跳回、不倒放。

### 2. 图注与绘图标准

1. **字体和字号：** 图内全部使用 STIX2/XITS 风格；屏上有效字号按“源码字号 × SVG 渲染宽 / viewBox 宽”计算。刻度最低 15px，普通标注最低 17px，关键读数/轴名建议 20-22px；验收红线为所有图内文字屏上有效字号 ≥17px（刻度经专项批准可 15-16px，但不得承担知识点）。上下标用 `tspan` 或 MathJax，不得平写 `K1`、`σa`。
2. **必备标注：** 开环极点 `×` 并标 `p₁,p₂,…`；开环零点 `○` 并标 `z₁,z₂,…`；实轴段；每分支 1-2 个方向箭头；分离/会合点 `●`，标坐标及 `K₁`；虚轴交点 `□`，标 `±jω` 及临界 `K₁`；渐近线标 `σₐ` 和角度；涉及性能时标 `ζ` 射线、阻尼角及目标闭环极点。无需出现的项目可省，但不得遗漏该页教材知识点。
3. **线条：** 主轨迹屏上 3-4px，当前分支可 4px；坐标轴 1.5-2px；渐近线 1.5-2px、`6 4` 或 `7 5` 虚线；零极点笔画 ≥3px；关键点大小在 2 倍截图下清楚。横纵轴严格等比例 1:1。
4. **颜色：** 对齐规范第 102 条：主深蓝 `#1D3FA0`（标题/主亮线），次蓝 `#2B5CE6`（轨迹），焦点红 `#D63A2F`（当前关键点/错误/终点，不作所有主线），渐近线橙 `#F5821F`，轴灰 `#5B6B8C`，次要刻度 `#8A97B5`，预轨迹 `#C9D6F2`。同一分支在同页和同例题连续页保持同色；不得继续使用与基线不一致的绿、紫、棕作为默认分支色。
5. **避让：** 标签最后绘制并加白色 halo；不得压曲线、轴、刻度、箭头或其他标签，不得贴边/出框。密集点用引线移到空白区。图放大 2 倍逐项核查。
6. **数值严谨：** 路径必须来自 `qa/rlocus_gen.py` 生成数据或解析圆，使用 `data/*.js` 中 branches/zeros/poles/breakaways/crossings/asym/pairs；关键点须与解析公式交叉核对。禁止徒手贝塞尔近似。

### 3. 排版标准

1. **正文目标：** 常规正文、步骤、表格正文统一以 22-24px 为主，最低 22px；标题/卡标题 26-32px；仅脚注和非教学性元信息可低至 18px。公式须相应放大并保留足够行距。
2. **覆盖率：** 每张内容页 `coverage ≥60%`；批次平均 ≥62%，全章可计量内容页平均 ≥62%，达到并略高于第四章 61.5% 基线。封面不套用 60% 算法，但须满足首屏视觉平衡。
3. **按内容选版式：**
   - 推导页：左侧 40%-46%“题设/推导步骤”，右侧 54%-60%“大图/验证”，底部结论条收口。
   - 法则页：左“法则+判据”，右“动态图”，底部“一句话速判”；不得只把一段文字置于上半页。
   - 比较页：等宽双栏或三栏，面板等高、基线对齐；同族页面像素级一致。
   - 表格页：表格占主体高度，列宽按内容设计；用“使用时机/易错点”卡补全，不用空卡凑数。
   - 稀疏公式页：将教材已有的推导依据、变量释义、计算检查升级为正式内容卡；禁止凭空发明结论。
4. **留白：** 四角和列表底部不得出现非常规大面积空白；主体内容垂直均布。内容不足时优先扩大核心图、提升字号、加入教材原有的推导/判据/旁注和结论条；不得靠无信息装饰、重复标题或大量小卡机械填充。
5. **卡片密度：** 每卡只承载一个教学任务，正文原则上不超过 2-3 行加一个公式；页面一般 2-4 个有意义内容块。禁止卡片套卡片、窄卡堆叠、同宽同高的机械宫格覆盖所有页面。
6. **结论条：** 用于本页 takeaway，并作为底部视觉收口；最多两行，距内容区 ≥15px，不遮挡。不是每页强制，但低覆盖页原则上应设置。

### 4. 量化验收方式

每一整改轮必须同时做以下四类验证，任何一类缺失不得送审：

1. **布局度量：** 运行 `qa/measure_layout.py` 生成本轮 JSON；报告逐页 coverage、avgFont/minFont、svgTextAvg/svgTextMin、playBtn、steps、svgCount。封面探针须修正或单列，不得用报错掩盖问题。
2. **全页截图：** 1448×1086 全量截图；动画页额外截初始/关键中间态/终态，互动页截初始/揭晓/解释态；1920×1080 和 1280×720 各抽查一轮缩放适配。
3. **功能探针：** 检查所有播放、重置、上一步、下一步；每幅图从 0 播到底、重置后再播一遍；检测 JS 错误、读数声明/写入/DOM 三方一致、动态标签不累积。
4. **数学与视觉复核：** 路径同数值参考叠图；关键点、渐近线、方向、稳定区间人工核算；每图放大 2 倍检查标注避让；同例题连续页并排比较。

**批次硬门槛：**

- 该批所有内容页 coverage ≥60%，批次平均 ≥62%。
- 正文教学文字 ≥22px 达标率 100%；图内普通/关键文字屏上有效 ≥17px 达标率 100%。
- 该批所有根轨迹图动画覆盖率 100%，每幅均有播放、重置、K/参数联动、步进与回退。
- 动画自动播放时长 8-15 秒；初/中/末三态无错位、无残影、无标签堆叠。
- 全批 0 个遮挡、出框、公式错误、图像 404、JS 报错；根轨迹数学核对 100% 通过。

### 2. 每轮审查提交物

每批提交时必须同时提供：

1. 修改后的对应 `qa/build_ch5_p*.py`、重建页面、数据文件变更清单；不得只交生成 HTML。
2. 本批逐页新版截图；每个动画页初始/关键中间态/终态三张，双图/参数变形页应覆盖每一种状态。
3. 本批新版布局度量 JSON 和“整改前→整改后”对照表，至少列 coverage、正文最小字号、图内有效最小字号、playBtn、steps。
4. 根轨迹数学核对表：开环零极点、实轴段、渐近线、分离/会合点、虚轴交点、出/入射角、稳定区间；不适用项写 N/A，不得空白。
5. 功能探针结果：播放、重复播放防竞态、重置、前进、回退、键盘步进、JS 控制台、读数绑定。
6. 本批审查问题清单及逐条回应。回应必须给页码和可见变化，不接受“已优化”类笼统表述。

### 3. 每批通过标准

- 批内所有非封面页 coverage ≥60%，平均 ≥62%；封面通过截图视觉审查。
- 正文 ≥22px、图内有效字 ≥17px 达标率均为 100%。
- 批内所有根轨迹图动画覆盖率 100%；每幅具备播放、参数联动生长、重置、步进和回退。
- 每幅动画经完整播放两遍无竞态、无卡死、无标签累积，关键点停顿与说明同步。
- 所有教材/spec 知识点保留；补充内容只来自教材文本、原逐页 spec 或将既有旁注/结论升级为正式内容卡。
- 0 个数学错误、0 个公式渲染错误、0 个遮挡/出框、0 个 JS 报错、0 个资源缺失。
- 审查人逐页给出“通过”；任一页不通过则整批状态为“待整改”。

### 4. 多轮审查机制

1. **首轮结构审查：** 看版式、字号、覆盖率、知识点完整性和动画叙事脚本；不合格先改结构，不进入细节润色。
2. **第二轮图形审查：** 每个根轨迹播一遍，审查数学形状、速度、方向、关键点停顿、标注清晰度和图文联动。
3. **第三轮投影审查：** 在 1920×1080、1280×720 和页面 50% 视觉尺度检查后排可读性、留白、遮挡和整体均衡。
4. **回归轮：** 全章 68 页连播，检查同族一致、跨页数值一致、键盘步进、封面/互动页以及上一轮所有修复点。发现问题继续循环，不设固定轮数上限。
