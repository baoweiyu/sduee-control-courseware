# 第五章《根轨迹法》根轨迹制图规范

**版本：** RL-DRAW-1.0  
**日期：** 2026-09-13  
**适用范围：** `lessons/lesson05-root-locus/fig.js` 及第五章全部根轨迹图。  
**地位：** 本文件是第五章根轨迹图的唯一视觉标准。任何页面级样式、临时颜色、临时线宽、临时字号与本文件冲突时，以本文件为准。  
**兼容性：** 继承第四章已认可的 STIX2/XITS 数学字体、红色 `#D63A2F` 强调色、蓝系主色和固定舞台缩放体系；本文件只把这些原则细化为可执行参数。

---

## 1. 不可违反的总原则

1. 根轨迹曲线只能来自 `data/*.js` 的数值采样，或明确声明的解析圆方程；禁止页面内徒手贝塞尔曲线、CSS 曲线和示意折线冒充计算结果。
2. 所有数学坐标采用等比例映射；同一数学单位在横、纵方向的屏幕像素长度相同，误差不得超过 1%。
3. 视觉层级固定为：稳定域/底轨 → 网格/坐标轴 → 渐近线/ζ 射线 → 主根轨迹 → 端点/拖尾 → 零极点和关键点 → 文字和徽章。
4. 文字必须最后绘制，关键文字必须有白色 halo；任何文字与曲线、坐标轴、刻度、其他文字重叠均视为失败。
5. 图面必须让学生同时看到“从哪里出发、沿哪条轨迹运动、K 增大方向、在哪里分离/穿越、最终去哪里”。只有一条裸曲线而缺少这些语义元素的图不合格。
6. 视觉增强不得改变数学含义。底纹、光晕、拖尾和徽章只能强调已有数据，不能添加不存在的根、零点或关键值。

## 2. 设计尺寸与坐标构图

### 2.1 统一 viewBox

| 图型 | viewBox | 适用场景 |
|---|---|---|
| 标准单图 | `0 0 960 600` | 单个根轨迹、法则示例、静态例题 |
| 动画单图 | `0 0 960 600` | P6、P19、P30、P37、P47、P66 |
| 双图对照 | 每幅 `760 520` | P21、P54、P67 |
| 小型三图 | 每幅 `540 300` | P61、P67 等归纳页 |

页面可以通过 CSS 缩放 SVG，但不得改变 viewBox 内数学比例；不得通过不同宽高拉伸圆或渐近线。

### 2.2 标准边距

标准单图内的坐标与内容边界固定如下：

- 左边距 `60px`；右边距 `28px`；上边距 `30px`；下边距 `48px`。
- 数学绘图区建议范围：`x=60..932`、`y=30..552`。
- 坐标轴箭头尖端距 SVG 边界至少 `16px`；轴名起点距箭头尖端至少 `18px`。
- 图例区域固定在右上角：默认左上角 `(690, 48)`，最大宽度 `230px`，不得盖住关键点；若右上有轨迹，自动迁移到左下 `(76, 500)`。
- 问题标签固定在左上角 `(76, 52)`，最大宽度 `360px`；问题标签与轴名、极点标签的净空不小于 `18px`。
- 关键点标签不得贴边：文字包围盒距 viewBox 四边至少 `12px`；若计算后越界，按优先级“向外引线 → 换象限 → 移到图外侧说明卡”处理，禁止裁字。

### 2.3 图卡占比

- SVG 占所属图卡内容高度的 `78%~88%`，占内容宽度的 `92%~96%`。
- 图卡标题条高度 `46~54px`，标题与 SVG 顶边间距 `10~14px`。
- 图面有效覆盖率（轨迹、标记、坐标、底纹、图例、徽章实际占用区域/绘图区）不得低于 `60%`；动画重点页目标 `65%~80%`。
- 图面不能靠放大空白范围“填充”页面。若轨迹本身集中在局部，必须通过局部 inset、关键点放大徽标或右侧读数卡补足信息，不得改变主坐标范围。

### 3.2 对比度规则

- 关键正文和关键图内文字必须达到白底 `4.5:1` 以上；大号文字（≥24px）不得低于 `3:1`。
- `#8A97B5`、`#C9D6F2`、`#F5821F` 不得单独用于关键读数、K 值、稳定性结论或轴名。
- 绿、橙分支必须用 `stroke-width≥5px`，所有标签配白 halo；禁止以 1~2px 细线在白底上表达主分支。
- 投影模拟：将截图转为灰度后，主轨迹与背景的亮度差必须≥40/255；将截图缩放到 50% 后，主标注仍能辨认。
- 禁止新增未列入色板的强调色，尤其禁止浅紫、浅橙、荧光绿和多种渐变。

### 3.3 分支配色策略

1. 颜色由 `data.pairs` 固定指定，`pairs=[[i,j],...]` 的共轭分支必须使用完全相同 HEX。
2. 没有 `pairs` 时只能作为兼容兜底，按起点共轭自动配对；新数据必须补 `pairs`，不得依赖兜底。
3. 同一例题的静态页、动画页、对照页使用相同分支颜色；左右对照图中同一数学分支必须同色。
4. 红色分支仍保留 R4 的分支序号语义，但在有“当前焦点/错误/警示”状态时，当前焦点外框和说明卡边框同步采用红色；不得把整页所有元素变红。

## 4. 曲线风格与辅助线

### 4.1 主根轨迹

- 主轨迹：`stroke-width:5px`，`fill:none`，`stroke-linecap:round`，`stroke-linejoin:round`。
- 静态图和动画终态必须使用同一宽度和同一数据路径；不能用静态细线、动画粗线两套几何。
- 曲线采样点之间必须使用原始数值折线；裁切只能采用 Liang-Barsky 分段求交或 SVG `clipPath`，不得逐点把越界坐标钳到边界。
- 曲线分支每 `0.55×N` 采样位置设置第一枚方向箭头；若该位置落在视口外，则沿当前分支向视口内寻找最近可见切线位置。箭头间距在长分支上为 `0.32~0.48` 个轨迹长度，短分支至少 1 枚。
- 方向箭头必须表示 K 增大方向：从开环极点向有限零点或无穷远；箭头不得固定在起点。

### 4.2 实轴根轨迹段

- 实轴满足段使用对应分支颜色，`stroke-width:7px`，`opacity:1`，端帽圆角。
- 可在实轴段下加 `16~22px` 高的浅蓝色带，填充 `#C9D6F2`、透明度 `0.18`；底纹不能覆盖极点/零点符号。
- 不满足段使用 `#8A97B5`、`stroke-width:2px`、`opacity:0.55` 的细基线或不绘制；不得使用红色表示“不满足”。

### 4.3 预览底轨

- 动画页必须先绘制完整预览底轨，再绘制动态亮轨迹。
- 底轨颜色 `#C9D6F2`，线宽 `2.2px`，透明度 `0.9`，不显示方向箭头和端点。
- 底轨必须与亮轨迹来自同一数据点列；亮轨迹和端点不得出现“不同步”或“端点领先/滞后”。
- `static:true` 页面可隐藏底轨，但不能删除数据路径；动画页 reset 后底轨保持显示。

### 4.4 渐近线

- 线色 `#F5821F`，线宽 `2.4px`，`stroke-dasharray:"8 6"`，不透明度 `0.9`。
- 渐近线从 `σ_a` 出发，使用射线与 viewBox 矩形求交；不得把端点钳在某一边后继续水平延伸。
- 交点处绘制半径 `18px` 的橙色空心圆环，线宽 `2px`，透明度 `0.75`。
- 角度必须用半径 `30~44px` 的圆弧表示，圆弧线宽 `2.2px`，标签为 `φ=±60°`、`φ=180°` 等；禁止只放无几何依据的角度文字。
- 若 180° 渐近线与负实轴重合，使用一条渐近线和一个角度徽章，不重复堆画两条完全重合的线。

### 4.5 ζ 射线

- 线色 `#7A4E2D`，线宽 `2.4px`，`stroke-dasharray:"3 5"`，透明度 `0.9`。
- 射线从原点出发，按 ζ 定义的阻尼角计算，并与 viewBox 求交；标签固定显示 `ζ=0.5` 等真实参数。
- 射线不得穿过关键点徽章和文字；必要时只移动标签，不修改射线数学方向。

## 5. 字体、字号与 halo

### 5.1 统一字体栈

SVG 内所有文字统一使用：

```css
font-family: "Cambria Math", "STIX Two Math", "Lesson03 STIX2", Georgia,
             "Times New Roman", "Microsoft YaHei", serif;
```

如果工程已加载本地 STIX2 字体，应优先在第五章局部 CSS 中声明 `Lesson05 STIX2`，其源文件使用现有 MathJax STIX2 WOFF2，不新增字体资源。禁止使用 Arial、Roboto、默认 sans-serif 作为图内数学文字首选字体。

### 5.2 960×600 源码字号

| 级别 | 源码字号 | 50%截图理论有效字号 | 用途 |
|---|---:|---:|---|
| 轴名 | 28px | 14px | `σ`、`jω` |
| 关键主标注 | 28px | 14px | `±jω,K₁`、`d,K₁`、当前 K |
| 主结论徽章 | 26px | 13px | 稳定/不稳定、圆心/半径 |
| 次标注 | 24px | 12px | `p₁`、`z₁`、角度、ζ |
| 图例 | 22px | 11px | 分支名称、底轨说明 |
| 刻度 | 21px | 10.5px | 数学刻度数字 |
| 引线辅助文字 | 20px | 10px | 短说明、非关键引线 |
| 徽章文字 | 24px | 12px | `K₁=...`、`σ_a=...` |

“50%截图理论有效字号”是远端可读性模拟，不取代浏览器实际 SVG 缩放测量。实际验收另加：屏上有效字号 = 源码字号 × `svg渲染宽/viewBox宽`，刻度不得低于 `14px`、内容标注不得低于 `16px`；当缩放比低于 `0.8` 时必须扩大 SVG 或移走次要文字，不能继续缩小字体。

### 5.3 粗斜体和上下标

- 轴名 `σ`、`jω`、变量名使用 `font-style:italic`、`font-weight:700`。
- 关键数值和中文说明使用 `font-style:normal`、`font-weight:700`；不把整句中文设为斜体。
- 极点/零点标签采用 `p_{1}`、`z_{1}`；参数采用 `K_{1}`、`σ_{a}`；阻尼比采用 `ζ`。
- 轻量下标使用 `<tspan dy="6" font-size="72%">1</tspan>`，绘制后用 `<tspan dy="-6">` 恢复基线；复杂公式使用 MathJax `foreignObject`。
- 禁止平写 `K1`、`sigma_a`、`wn`、`ts`。

### 5.4 halo

- 所有主标注、次标注、关键点标签和图例文字默认启用：

```css
paint-order: stroke;
stroke: #FFFFFF;
stroke-width: 6px;
stroke-linejoin: round;
```

- 20px 以下辅助文字 halo 宽度固定为 `4px`；不得把 halo 取消后让曲线穿过文字。
- 文字必须在所有线条和点之后最后绘制；图层顺序不能由 DOM 偶然决定。

## 6. 标记几何与标签避让

### 6.1 开环极点 ×

- 中心位于数学坐标映射后的 `(X(p.real),Y(p.imag))`。
- 两条对角线长度各 `24px`，即半径 `12px`；线宽 `4px`；端帽 `round`；颜色 `#16324F`。
- 极点标签默认放在点的上方 `18px`，文本基线偏移 `−18px`；下方空间不足时移动到右上方，水平引线不少于 `18px`。
- 共轭极点标签不得分别贴在同一垂直线上；上点标签右上、下点标签右下，净空至少 `12px`。

### 6.2 开环零点 ○

- 外径 `24px`，半径 `12px`；填充 `#FFFFFF`；边框 `#16324F`，线宽 `4px`。
- 标签默认放在零点上方 `18px`；若与其他标签冲突，依次尝试左上、右上、左下、右下四个象限。
- 零点和极点距离小于 `36px` 时必须自动进入“密集标记”模式，标签使用引线，不得直接相邻堆叠。

### 6.3 分离点/会合点 ●

- 外圈光晕半径 `14px`，填充对应关键色，透明度 `0.22`。
- 实心中心半径 `8px`，填充 `#B3541E`，白色描边 `2px`。
- 关键点文字统一格式：`d=-0.4226, K₁=0.3849`，字号 `24px`，粗体，白 halo。
- 关键点到标签的引线：起点离圆心 `10px`，终点离文字包围盒 `8px`，长度 `26~64px`，默认方向右上或左上；不得穿过另一条曲线。
- 同一图多个关键点按“上方优先、下方次之、左右最后”分区；标签之间的包围盒间距至少 `12px`。

### 6.4 虚轴交点 □

- 正负交点各绘制空心方块 `18×18px`，边框 `#B3541E`，线宽 `3px`，填充白色。
- 对输入 crossing 数据按 `abs(s)` 去重；每个唯一频率只绘制一次上下方块和一个标签。
- 标签统一格式：`±j1.4142, K₁=6`；标签放在上方交点右侧，距方块边缘 `18px`，字号 `24px`，带 halo。
- 如果上方交点超出 viewBox，仅绘制视口内的方块；标签迁移到右侧说明卡，但不得把下方标签写成单独的 `jω` 而缺 K。

### 6.5 重根复合符号

- 重根中心先绘制半透明外环：半径 `16px`，颜色 `#D63A2F`，透明度 `0.18`。
- 再绘制直径 `22px` 的空心圆，边框 `#D63A2F`，线宽 `3px`。
- 最后叠加两条长度 `18px`、线宽 `3px` 的十字线，颜色 `#D63A2F`。
- 标签格式：`重根 s=-1, K₁=1`；标签字号 `24px`，不得与圆心重叠。

### 6.6 标签避让优先级

发生冲突时严格按以下顺序处理：

1. 改变标签所在象限；
2. 增加 `26~64px` 引线；
3. 将次标注移到图例或右侧说明卡；
4. 扩大局部 inset；
5. 最后才调整主图坐标范围，并且同一例题全组同步调整。

禁止降低字号、减细主轨迹或删除关键标记来解决冲突。

## 7. 图例、问题标签与徽章

### 7.1 图例

- 图例每项由 `46px` 长颜色线 + `22px` 文字组成，行高 `40px`。
- 主轨迹图例至少包含：`分支 1/2/...`；动画页另含 `预览底轨`、`当前闭环极点`。
- 图例背景白色透明度 `0.96`，边框 `#C9D6F2`，线宽 `1.5px`，圆角 `8px`；不得覆盖任何轨迹。
- 不得用颜色替代文字；共轭分支在图例中合并为一项，例如“分支 1（共轭对）”。

### 7.2 问题标签

- 问题标签使用 `#1D3FA0`、字号 `24px`、粗体、白 halo。
- 文案必须是一个可讲授问题，例如“`K₁` 增大时闭环极点如何运动？”；长度不超过 `24` 个汉字。
- 问题标签只放左上，不得与坐标轴名或极点标签争抢位置；静态归纳图可关闭。

### 7.3 K 读数徽章

- 背景 `#FFFFFF`，边框和文字 `#D63A2F`，边框 `2.4px`，圆角 `9px`，内边距横向 `10px`、纵向 `7px`。
- 徽章字号 `24px`；格式必须为 `K₁=...`、`a=...` 或页面真实参数，不得写无来源的估计值。
- 动画 K 徽章固定在图右下区域，默认中心 `(790,530)`；与刻度文字、结论条的净空至少 `16px`。
- 分离点/虚轴交点标签内已有 K 时，不再在同一位置重复放第二个 K 徽章。

## 8. 动画视觉标准

### 8.1 通用动画状态

每个动画页必须有 `0..T` 步，并由 `ACT.step` 驱动；`paint(step)` 每次先清空 `gDyn`，再重绘当前动态状态。静态底轨、坐标、稳定域、渐近线、零极点属于静态层，不随帧累积。

推荐状态层：

1. `gRegion`：稳定域/实轴底纹；
2. `gGrid`：轴、刻度和网格；
3. `gBase`：底轨、渐近线、ζ 射线；
4. `gBranch`：当前亮轨迹；
5. `gDyn`：端点、拖尾、当前 K、徽章、当前步高亮。

### 8.2 运动端点

- 每条可见分支端点绘制半径 `11px` 的实心圆，填充该分支色，白色描边 `3px`。
- 端点旁的当前根标签字号 `24px`，与端点水平偏移 `18px`、垂直偏移 `−12px`；冲突时转到相反侧。
- 每个端点绘制 `3` 个拖尾圆点，沿最近 `20` 个采样点取样：
  - 第1个拖尾半径 `9px`、透明度 `0.45`；
  - 第2个拖尾半径 `7px`、透明度 `0.20`；
  - 第3个拖尾半径 `5px`、透明度 `0.09`。
- 拖尾颜色与所属分支完全相同；拖尾只出现在 `gDyn`，reset 后必须消失。
- 端点必须取当前显示路径的最后一个原始采样点或插值点；端点与亮轨迹末端距离不得超过 `1px`。

### 8.3 K 进度条

- 位置：图内右下 `(650,540)` 起，宽 `230px`，高 `14px`。
- 底轨 `#E7EDF9`，边框 `#C9D6F2`、线宽 `1.5px`、圆角 `7px`。
- 已完成部分填充 `#2B5CE6`；当前焦点或跨越稳定边界时填充 `#D63A2F`。
- 左侧标签字号 `22px`，显示 `K₁`；右侧显示当前数值，字号 `22px`、粗体、墨色 `#16324F`。
- K 映射必须使用对数进度：`f=log10(K/Kmin)/log10(Kmax/Kmin)`；不得用线性 K 映射代替。

### 8.4 当前步联动

同一步中以下元素必须同步变化：

- 亮轨迹颜色/可见长度；
- 运动端点和拖尾；
- 当前 K 或参数徽章；
- 关键点/虚轴交点徽章；
- 右侧当前步说明卡边框；
- 进度条填充。

当前焦点使用 `#D63A2F`；已经完成的历史步骤保持静止，不反复闪烁。单页同时闪烁对象最多 `1` 个。

### 8.5 时长和停顿

- 普通动画总时长 `8~12s`；重点动画总时长 `10~15s`。
- 关键事件（重根、分离点、虚轴交点、会合点）停顿 `0.8~1.2s`。
- 关键事件停顿期间：点徽章、K 徽章和右侧说明卡必须同时出现；轨迹不得继续移动。
- 播放按钮只启动一次播放；再次点击变为暂停；暂停后继续不重置。重置按钮必须将步数、曲线、端点、拖尾、徽章和说明卡全部恢复到第 0 步。
- `window.prev` 使用重放式回退：先 `reset()`，再从第 0 步调用 `next()` 到目标步；禁止只反向修改一个进度变量。

## 9. 各类页面的最低图面配置

### 9.1 静态法则图

必须有：坐标轴箭头、至少一个极点/零点符号、主判据或辅助线、图例或语义说明、关键标签。若页面讲实轴段，必须有段底纹或加粗段；若页面讲渐近线，必须有交点圆环和角弧；若页面讲分离点，必须有 ● 与 K；若页面讲虚轴，必须有上下 □ 与 `±jω,K₁` 标签。

### 9.2 例题图

必须有：完整数据轨迹、零极点标签、关键点标签、K 数值、方向箭头、与右侧公式/说明卡一一对应的引线。只显示一条无标注曲线的例题图不合格。

### 9.3 动画图

必须有：完整浅色底轨、当前亮轨迹、端点、3级拖尾、方向箭头、K 进度条、当前步说明、事件停顿和 reset/prev。纯 stroke-dashoffset 而没有运动端点或读数联动不合格。

### 9.4 对照图

必须有：同一坐标比例、同一主图尺寸、同一分支色、相同图例位置和对应事件徽章。左右图不能一个使用裸轨迹、另一个使用完整标注。

## 10. 禁止清单：导致“丑/不可读”的直接原因

以下任一项出现，图面验收直接失败：

1. 主根轨迹线宽低于 `5px`，或实轴根轨迹低于 `7px`。
2. 极点 × 小于 `24×24px`，零点直径小于 `24px`，关键点小于 `16px`中心尺寸。
3. 图内主标注源码字号低于 `26px`，轴名低于 `28px`，刻度低于 `20px`（除非经过屏上有效字号复核并有批准）。
4. 在白底上使用 `#8A97B5` 或 `#C9D6F2` 书写关键结论、K 值或主轴名。
5. 没有图例，或图例只使用颜色线而没有分支名称。
6. 共轭分支使用不同颜色，或同一分支在不同页面改变颜色。
7. 方向箭头放在分支端点、起点，或箭头方向与 K 增大方向相反。
8. 箭头三角小于 `18×14px`，或箭头与曲线脱离超过 `10px`。
9. 虚轴交点只画一个方块、只标 `jω`、缺少 `K₁` 或上下方块重叠。
10. 分离点/会合点没有 K，或标签写成无下标的 `K1`。
11. 标签压在曲线、轴线、刻度或另一个标签上；标签被 viewBox 裁切；文字没有 halo 导致线穿字。
12. 用逐点 `Math.max/min` 把越界数学坐标钳到图框边缘，造成假平尾、边框轨迹或方向错误。
13. 用 CSS 拉伸 SVG，使圆变椭圆或渐近线角度改变。
14. 图内堆满深色框、渐变、阴影、彩色圆斑、无数学含义的装饰。
15. 用浅蓝底轨当作主轨迹，或用低对比辅助线表达结论。
16. 动画只有线条变长，没有端点、拖尾、K 读数或关键事件停顿。
17. 动画每帧向 SVG 根节点追加标签，导致文字累积、重影或重复徽章。
18. reset 后仍保留端点、拖尾、红色高亮或旧步数徽章。
19. 同一页多个图没有对齐基线、图框大小不同、字号不同或颜色不一致。
20. 为填空删除原教材关键公式、数值、分离点、虚轴交点或例题对照信息。
21. 把整页所有元素涂成红色；红色只能表达当前焦点、错误、警示或终点。
22. 将中文整段设为斜体、将公式写成普通文本，或把下标平写。
23. 图卡下半部空白超过图卡高度的 `25%`，却把图缩在上半部。
24. 通过缩小字号解决拥挤，而不是使用引线、象限避让或局部 inset。

### 11.1 配置落地规则
