# 第五章《根轨迹法》版式重设计 Spec

**版本：** LAYOUT-RDS-1.0（2026-09-13）  
**适用范围：** `lessons/lesson05-root-locus/` P1-P68。  
**依据：** 第五章逐页 spec、R1-R10、制作规范第 43-48、93-104、109、112-113 条，以及现有课件知识点。  
**目标：** 以内容决定版式，不再使用所有页面同一“左卡+右卡+底条”结构；页面有效内容区覆盖率 60% 以上，重点页 65%~80%，正文和图内文字满足投影可读性。

## 1. 统一版式基线

### 1.1 设计网格

- 固定设计画布 1440×900；`.act-stage` 全屏，`.act-slide` 左上为变换原点，使用既有 fit 缩放。
- 内容安全区：左 60px、右 60px、上 46px、下 128px（有结论条）；页眉标题区高 54px。
- 主内容采用 12 列栅格：列宽 `calc((100% - 11×18px)/12)`，列间距 18px；卡片间距 18~24px。
- 卡片内边距：大卡 22~28px，小卡 16~20px；标题条与正文间 12~16px。
- 任何页面不得以空白作为“平衡”；若内容不足，添加本页相关的速判卡、工程解释、局部放大图或步骤轨道，不添加装饰性空话。

### 1.2 字号阶

| 层级 | 设计字号 | 用途 |
|---|---:|---|
| 章标题 | 46~54px | P1 |
| 部分标题 | 38~44px | P2/P31/P43/P56 |
| 页标题 | 28~32px | 普通页页眉 |
| 卡片标题 | 23~26px | `.hd` |
| 正文 | 20~22px | 解释、定义、步骤 |
| 公式 | 25~34px | 长公式可拆两行，不压缩到 <22px |
| 互动题题干 | 26px | 选项 21~22px |
| 图主标注 | 26~30px | 关键点、K、稳定结论 |
| 图次标注 | 23~25px | 极点、角度、引线 |
| 图刻度 | 20~22px | 投影可读 |
| 结论条 | 22~25px | 最多两行 |

所有字号须按屏上有效字号复核；禁止将含公式的页眉拆成多个 flex 子项，公式整体包在 `span style="flex:1"` 内。

### 1.3 覆盖率与留白

- 普通知识页：有效内容（卡片、图、表、公式、步骤轨道）占内容区 60%~78%。
- 关键动画页：主图占左侧 58%~66%宽、72%~82%高；侧栏占 30%~36%宽。
- 表格页：表主体占内容区 72%~84%高；表外只放一个结论/辨析卡。
- 互动页：题目与选项占 58%~68%宽或高；速判卡占 25%~32%；解释条在第二步出现，不预留大块空白。
- 结论条与 `.act-body.has-note` 必须配对；结论条不超过两行，不遮挡正文。

## 2. 六种版式母版

### M1 解释图左·推导右

- **栅格：** 左 7 列图、右 5 列公式/说明；左右高度一致。
- **适用：** 法则、公式、单个例题推导。
- **填充顺序：** 左上问题标签→主图→图例/关键点；右上定义→公式→筛选/结论卡。
- **差异要求：** 图不能只占卡片上半；右栏最多 4 个块，每块正文≤2行+1公式。

### M2 双栏对照

- **栅格：** 两个 6 列等宽面板，标题和图底线对齐；底部跨 12 列放结论。
- **适用：** 180°/0°、两系统、两种方法、例题双口径。
- **填充顺序：** 左条件/图→右条件/图→跨栏结论。
- **差异要求：** 两图使用同一 viewBox、xlim/ylim、字号和色系，不能一个大一个小。

### M3 三步/五步流程型

- **栅格：** 左 8 列主图或流程，右 4 列步骤卡；顶部横向步骤轨道占 1 行。
- **适用：** 根轨迹绘制流程、动画、法则链。
- **填充顺序：** 步骤轨道→主图→当前步说明→K/性能读数。
- **差异要求：** 每个步骤必须有可见状态变化；不能用一张最终图配一串按钮。

### M4 表主体·侧栏

- **栅格：** 表格 9 列，侧栏 3 列；表头和行高固定，侧栏放速判/易错卡。
- **适用：** 特征根数值表、法则总表、综合对照表。
- **填充顺序：** 表题→表主体→侧栏说明→结论。
- **差异要求：** 表格行高足够，文字不换成竖排；每一行可在投影端读出。

### M5 图文混排·上下结构

- **栅格：** 上部 5 列文字+7列图，或上部全宽图、下部三卡；图高至少 42%。
- **适用：** 引言、性能规律、工程背景、章节总结。
- **填充顺序：** 一句问题→主视觉→3~4个知识卡→结论。
- **差异要求：** 不使用空白撑高；每个知识卡与图中一个元素有对应关系。

### M6 封面/章节过渡

- **栅格：** 左 6 列标题与目录，右 6 列 image2/抽象图；背景图透明度≤18%。
- **适用：** P1、P2、P31、P43、P56。
- **填充顺序：** 部分标签→大标题→目录/关键词→右侧图片。
- **差异要求：** 不放页眉页脚；不把抽象装饰线当严谨根轨迹数据图。

## 7. 执行纪律

1. 只改第五章页面及第五章共享绘图库；不改前四章、不改全局 `theme.css`，除非另行批准。
2. 版式母版可在第五章目录新增局部 CSS，但公共变量命名要清楚，避免覆盖既有章节。
3. 每个页面必须保留原 spec 的知识点、公式和数值；“减少留白”不得通过删除教材内容实现。
4. 图面重设计先改共享 `fig.js`，页面只传配置；不得在 31 个页面分别复制坐标裁剪、徽章、动画算法。
5. 动画页按 0/中/终态截图；静态页按重点图局部放大复核。任何新增 CSS 或公共 JS 修改后，至少复核 3 个同族页。
6. 结论条、答案条、错误提示等文本不得超过两行；所有短标签使用 `nowrap`。
