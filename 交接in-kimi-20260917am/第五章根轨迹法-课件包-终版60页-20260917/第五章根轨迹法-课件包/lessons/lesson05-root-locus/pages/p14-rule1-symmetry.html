法则内容（n\geq m）
分支数 = 闭环极点数 = 开环极点数 n：每个开环极点出发一条分支（K_{1}=0 时根就是开环极点）。
根轨迹连续：特征根随系数 K_{1} 连续变化，故轨迹是连续曲线。
对称于实轴：实系数特征方程的复根必共轭成对出现，轨迹上下镜像对称。
怎么来的
特征方程 D(s)+K_{1}N(s)=0 是 n 次代数方程（n\geq m），任意 K_{1} 对应 n 个根 → n 条分支。
多项式的根是其系数的连续函数，K_{1} 连续变化 → 根连续移动 → 轨迹连续。
实系数方程的复根必共轭成对 → 轨迹关于实轴镜像对称。
