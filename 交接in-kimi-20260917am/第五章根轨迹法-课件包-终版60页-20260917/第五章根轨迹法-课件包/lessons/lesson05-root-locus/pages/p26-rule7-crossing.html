法则内容（两种求法）
法① 劳斯判据：当劳斯表 s^{1} 行首元素变为零时，特征方程出现一对虚轴根，对应 K₁ 即临界增益；再用上一行（s^{2} 行）构造辅助方程，解出交点 \pm j\omega。
法② 代入 s=j\omega：特征方程实部、虚部分别为零，联立解出 \omega 与 K_{1}。
怎么来的
根轨迹穿过虚轴 ⟺ 闭环系统临界稳定 ⟺ 特征方程有纯虚根 s=\pm j\omega——两种求法都是"存在纯虚根"的代数表达。
示例（G(s)=\dfrac{K_{1}}{s(s+1)(s+2)}）
特征方程 s^{3}+3s^{2}+2s+K_{1}=0：劳斯 s^{1} 行 \dfrac{6-K_{1}}{3}=0\Rightarrow K_{1}=6；辅助方程 3s^{2}+6=0\Rightarrow s=\pm j\sqrt{2}
法② 验证：(K_{1}-3\omega^{2})+j\omega(2-\omega^{2})=0 → \omega=\sqrt{2}，K_{1}=6——两法互证 ✓
稳定性分界（本例）：0<K_{1}<6 稳定，K_{1}>6 不稳定。
K₁=6 时抵达 ±j√2（空心方块），越过即失稳
空心方块 = 虚轴交点 \pm j\sqrt{2}（K_{1}=6，临界）；淡红区 = 右半平面，轨迹进入则闭环不稳定（本例）。
K₁ = 0 0 / 3
要点两条方法各有适用场景：劳斯法顺手给出稳定范围，s=j\omega 法直接联立、不排表——结果必须一致。
