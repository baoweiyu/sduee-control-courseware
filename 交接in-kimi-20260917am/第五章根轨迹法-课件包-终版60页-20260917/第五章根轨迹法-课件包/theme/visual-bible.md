# Control Visual Bible —《自动控制理论》课程视觉规范 v0.1（初稿）

> 来源：`bwy-ori-template/` 30 张风格参考图（同一设计系统）+ image2 首件验证。
> 落地文件：`theme/theme.css`（本文件的 token 与版式均已实现为 CSS 变量/类）。
> 规则：后续页面优先复用；新增视觉语义先改 theme，再改页面。

## 1. 画布与栅格

- 页面比例 **4:3**，设计分辨率 **1448 × 1086**，整体缩放适配屏幕（等比，不裁切）。
- 页边距：左右 48 px，内容区上界 210 px（页眉之下）、下界 980 px（底栏之上）。
- 卡片圆角 20 px，卡片间距 24~32 px；布局以 2/3/4 列卡片为主。

## 2. 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| `--navy` #12266E | 页标题、结论文本、深色文字 |
| `--blue` #1D3FA0 | 页眉徽章、卡片标题栏、表头、底栏左带 |
| `--blue2` #2B5CE6 | 图标、强调图形、连接线 |
| `--sky` #EEF3FD | 卡片/提示条浅蓝底 |
| `--line` #C9D8F2 | 卡片描边、表格线 |
| `--orange` #F5821F | 标题下装饰线、"提示/结论"前缀、关键数字、底栏右带 |
| `--ink` #22304A | 正文 |
| `--muted` #5B6B8C | 注释、副文本 |
| 警示红 | #D63A2F | 仅用于不稳定/警示语义（模板未出现，新增语义，需克制） |

专业视觉语义：极点 × 用 `--orange`，零点 ○ 用 `--blue2`，稳定区域浅蓝 `--sky`，不稳定区域浅红；信号线实线 `--blue`，反馈通路加粗，扰动通路虚线 `--orange`。

## 3. 字体与层级

- 中文：Microsoft YaHei（系统字体栈，离线可用）；西文/数字同栈加 Segoe UI；公式暂用 Cambria Math/STIX 系 serif 斜体，数学密集章节接入离线 KaTeX（待办）。
- 页标题 44 px / 700 / `--navy`，居中；副标题 26 px；正文 24 px；注释 18~20 px；**最小字号 18 px（后排可读约束）**。
- 卡片标题栏 26 px / 700 白字蓝底；卡片正文 22~24 px。
- "提示/核心/结论"条：前缀 `--orange` 700，正文 `--navy`，左侧靶心图标。

## 4. 页眉 / 页脚（每页固定）

- 左上：蓝色斜切徽章 + 学士帽图标 +《自动控制理论》白字。
- 中上：页标题 + 橙色短横线（宽 110 px 高 8 px 圆角）+ 右侧小圆点。
- 右上：`n / N` 页码，`--navy`。
- 底部：左蓝色横带（含右侧斜切），右橙色斜切块；右下角页码数字白/深蓝。

## 5. 图形语言

- 图标：扁平线性图标，`--blue2` 2.5 px 线宽，浅蓝圆形底衬。
- 流程：卡片间用橙色粗箭头连接；编号徽章为白字蓝底圆（01/02…）。
- 方框图（程序绘制）：方框白底 `--line` 描边圆角 8 px，框内文字 `--navy`；求和点圆圈带 +/−；信号箭头 `--blue` 2.5 px；反馈线下绕行。
- 曲线图（程序绘制）：坐标轴 `--muted` 1.5 px，网格 `--line` 虚线，主曲线 `--blue2` 3 px，参考线/包络 `--orange` 虚线，关键点标记实心圆 + 真实文本标签。

## 6. Image 2 视觉语言（已用首件验证）

- 风格：扁平矢量工程插画，干净 2 px 描边，极轻阴影，白底，主体居中并留足叠加区。
- 色彩：深蓝主导（≈#1B3B8B）+ 橙色点缀（≈#F5821F），水体浅蓝。
- 禁令（工作说明 §2.3）：不出现文字、公式、坐标刻度、数学曲线；构图须为 HTML 叠加标注留白。
- 提示词模板、版本记录见 `assets/image2/prompts/*.json`。

## 7. 动效与交互

- 分步出现：淡入 + 上移 12 px，220 ms，ease-out；Space 顺序 = 教师讲解顺序。
- 参数联动：拖动实时更新（≤16 ms/帧），曲线过渡 120 ms。
- 状态色：可拖动 `--orange`，悬停加深，锁定/禁用 `--muted` 灰化。
- 不用装饰性动画；无交互时页面信息结构完整可读。

## 8. 课堂约束

- 4:3 等比缩放居中，1024×768 及以上不裁切；全屏黑边底色 #0B1440。
- 关键文字为真实 HTML 文本，关键公式为真实公式对象，绝不烘焙进图片。

## 9. 用户审阅固化的永久规则（v0.3，2026-08-26）

1. **单一强调色**：正文中的强调文字只用一种颜色——红色 `#D63A2F`（`--danger` / `.kw-r` / `.em`，主题已用 `!important` 兜底）。禁止红蓝绿混排高亮。橙色 `#F5821F` 只用于结构性元素：箭头、图标、时间轴圆点、「结论：/提示：」等前缀标签（`.lead`）。
2. **键盘与导航可靠性**：页面 iframe 必须转发键盘事件（`act-key`）与指针活动（`act-poke`）给播放器；播放器导航条随任何鼠标活动唤出、3 秒自动隐藏。改动播放器后必须实测：鼠标点击页面后 ← → / Space / Home / End 仍可用。
3. **图片优先 image2**：关键视觉图（设备、场景、示意）一律用 image2 引擎重新生成，禁止把旧 PPT 截图/照片直接贴入页面。旧素材只允许两类功能性真图：二维码、教材封面（放 `assets/legacy/`，其余提取图仅留档不引用）。数学图形、方框图、曲线图一律程序绘制（SVG/Canvas）。
4. **页面饱满**：禁止大面积留白；稀疏页面用 `.act-body.fill` 垂直居中并加大卡片内边距与字号，内容区应大致撑满 4:3 版面。
