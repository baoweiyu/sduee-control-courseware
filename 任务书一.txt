# 任务书一：基于经典 SFR 模型的 HTML 动态零极点与频率响应分析工具开发

## 1. 任务目标

围绕经典系统频率响应（System Frequency Response，SFR）模型，开发一套基于 HTML 的交互式动态分析工具，通过系统物理参数设置、参数区间扫描、闭环零极点轨迹与频率响应曲线簇的联动展示，直观揭示不同参数变化对系统动态特性的影响。

工具重点服务于后续经典控制理论研究，既要支持单独改变惯量、负荷阻尼、调频增益及原动机动态参数，也要支持通过不同方式改变时间常数比值，明确同一比值变化在不同参数约束条件下产生的差异。

工具应能够单独部署于 GitHub Pages 或 Cloudflare Pages 等静态网页平台，不依赖后端服务器完成常规数值计算。

## 2. 模型建立与计算基础

### 2.1 采用的系统模型

采用前期报告中的低阶 SFR 模型，扰动输入为净有功功率扰动，输出为系统频率偏差标幺值。

前向通道：

`G_p(s) = 1/(2Hs+D)`

反馈通道：

`G_f(s) = K_F(1+F_H T_R s)/(1+T_R s)`

对应的扰动闭环传递函数：

`G_d(s) = (1+T_R s)/[2H T_R s² + (2H+(D+K_F F_H)T_R)s + D+K_F]`

其中，H 为惯性常数，D 为负荷频率阻尼系数，K_F 为调频增益，T_R 为再热时间常数，F_H 为高压缸快分量比例。

工具应统一功率和频率标幺值定义，并明确正负荷阶跃对应负的频率响应。

### 2.2 参数体系

| 类型 | 参数 | 定义 |
|---|---|---|
| 基础独立参数 | H | 惯性常数 |
| 基础独立参数 | D | 负荷频率阻尼系数 |
| 基础独立参数 | K_F | 调频增益，K_M/R |
| 基础独立参数 | T_R | 再热时间常数 |
| 基础独立参数 | F_H | 快通道比例 |
| 派生参数 | T₁ | 2H/D |
| 派生参数 | K₁ | 1/D |
| 派生参数 | T₂ | T_R |
| 派生参数 | λ | T₁/T₂ |
| 辅助参数 | k | K_F/D |
| 辅助参数 | T_m | √(T₁T₂) |

基础独立参数应作为模型计算的权威参数源。派生参数与基础参数必须实时关联，不能出现修改 T₁ 后 H、D 及其他派生量相互矛盾的情况。

例如，单独调整 T₁ 时应提供两种选择：固定 D、相应改变 H；或者固定 H、相应改变 D。默认采用固定 D 的方式。

### 2.3 计算与显示的系统特征量

根据闭环传递函数计算：

- 自然频率 ωₙ；
- 阻尼比 ζ；
- 闭环极点 p₁、p₂，包括实部、虚部及模长；
- 扰动闭环零点 z_c；
- 必要时另行显示反馈通道零点 z_f，并与 z_c 使用不同符号区分；
- 闭环主导极点实部绝对值；
- 系统阻尼状态：欠阻尼、临界阻尼或过阻尼。

需要特别处理 F_H=1 时的极零相消。此时显示实际约简后的一阶系统极点，不能把已经相消的零极点继续作为系统实际动态模态。

## 3. 功能一：自定义参数初始值和变化范围

### 3.1 参数设置界面

工具启动后，首先进入参数配置区域。

支持用户填写 H、D、K_F、T_R、F_H 的初始值、允许最小值和最大值，指定需要分析的参数，以及对应的扫描方式。

同时支持额定频率、负荷扰动幅值、频率响应仿真时长及扫描精度等设置。

各参数的工程正常范围**不由程序预先认定**，由用户根据具体系统和研究对象输入。工具只提供必要的数学合法性检查，例如时间常数、惯量应为正，快慢比例模型中的 F_H 处于 0～1 范围。

对于 D=0 等导致 T₁、K₁ 无法按常规形式计算的特殊情况，工具应提示改用未归一化的物理模型计算，不能出现除零错误。

### 3.2 参数范围有效性检查

工具应自动判断：

1. 初始值是否位于用户指定的范围之内。
2. 扫描过程中是否出现不符合输入约束的组合。
3. 派生参数变化是否导致基础物理参数超过允许范围。
4. 是否存在临界阻尼、极点重合或零极点相消等特殊工况。

对于超出允许范围的工况，应提供明确提示或将其排除，不应隐含使用未获用户确认的工程参数范围。

### 3.3 参数配置保存

提供参数配置的 JSON 导入与导出功能，便于保存不同电网模型、研究场景和对比实验，保证后续重复分析时使用完全相同的参数。

## 4. 功能二：参数变化路径选择

### 4.1 单一物理参数扫描

支持分别扫描 H、D、K_F、T_R、F_H。

扫描某一物理参数时，默认保持其他基础独立参数不变。工具同步更新全部派生参数、零极点、特征量及频率响应。

### 4.2 T₁ 的专项扫描

支持将 T₁ 作为直接分析变量，分别选择：

- 固定 D，通过改变 H 调整 T₁；
- 固定 H，通过改变 D 调整 T₁。

两种情况应分别计算，因为第二种情况会同时改变 K₁ 和 k。

### 4.3 λ=T₁/T₂ 的三种变化路径

**路径 A：固定 T₁，改变 T₂。**

保持 T₁ 不变，根据 `T₂=T₁/λ` 更新 T_R。在默认固定 D 的条件下，H 不变。

**路径 B：固定 T₂，改变 T₁。**

保持 T_R 不变，根据 `T₁=λT₂` 更新 T₁，并在固定 D 的条件下计算对应 H。

**路径 C：T₁、T₂ 同时变化。**

默认采用固定几何平均时间常数 T_m 的方式：

`T₁=T_m√λ`，`T₂=T_m/√λ`

同时预留用户自定义两者关联变化方式的功能。

三种路径必须分别标识。不能仅根据 λ 相同就认为系统的实际极点位置或频率响应时间尺度完全相同。

对于每条路径，都应自动计算它与用户指定的 H、D、T_R 等物理参数范围的交集。

## 5. 功能三：双图动态联动

### 5.1 左图：闭环零极点参数轨迹

左图为复平面零极点动态分析图，横轴是极点或零点的实部，纵轴是虚部，单位为 s⁻¹。

当扫描变量变化时，绘制对应的闭环极点轨迹及闭环零点位置变化。

要求：

1. 使用统一图形符号区分闭环极点与闭环零点。
2. 对不同扫描位置建立完整的参数对应关系。
3. 用少量箭头或颜色渐变表示扫描参数由小到大的变化方向。
4. 对极点折返、分支合并、由复数变为实数等情况正确显示。
5. 对固定不动的零点仅显示固定位置，不人为绘制不存在的运动轨迹。
6. 坐标轴支持自动缩放、手动范围调整、局部放大及恢复视图。
7. 提供实轴与虚轴等比例坐标选项，以便正确观察极点夹角。
8. 图例避免大量数字标注，默认只展示必要信息。

需要在界面上注明：当扫描 H、D、T_R 等参数时，这属于**参数化闭环零极点轨迹**，并不一定是经典控制理论中仅改变环路增益的标准根轨迹。

### 5.2 右图：匹配的频率响应曲线簇

右图展示与左侧零极点参数轨迹对应的一组负荷阶跃频率响应曲线。

基本要求：

1. 每条频率响应曲线对应明确的一组模型参数。
2. 通过颜色渐变或少量方向箭头反映参数由小到大时的频率响应变化趋势。
3. 支持显示频率最低点及其出现时刻。
4. 支持显示准稳态频率参考线和选定的 2% 整定误差带。
5. 同一组计算结果下，左右两图的参数索引必须完全一致。
6. 支持切换实际频率曲线、归一化频率跌落曲线，避免改变 D 或 K_F 时准稳态值不同导致误判。
7. 支持自动与手动设置时间轴范围；整定时间超出计算时长时须明确提示。

为避免大量曲线遮挡，可采用“高密度零极点轨迹＋适量背景频响曲线＋任意选中工况实时精确重算”的方式。

## 6. 功能四：交互、点选及高亮

### 6.1 点击根轨迹选取工况

用户点击任意闭环极点轨迹附近的位置后，程序应识别对应的扫描参数值。

选中后：

- 左图其余轨迹弱化，当前点高亮；
- 共轭极点及当前闭环零点同步高亮；
- 显示选定参数值、极点复数值及极点模长；
- 右图其余响应曲线弱化；
- 当前参数对应的频率响应曲线高亮显示；
- 右图标记频率最低点和必要的动态指标。

对于同一复平面位置对应多个扫描参数的情况，应提供候选值选择或利用最近一次选择消除歧义，不能任意选取。

当零点固定不动时，点击固定零点本身不能唯一决定参数值，应保持当前工况或提示用户通过极点轨迹和滑块选取。

### 6.2 参数滑动条

在双图附近设置参数 Slider。

拖动 Slider 时，实时改变选中参数，并同步更新：

- 当前闭环零极点位置；
- 当前高亮频率响应曲线；
- 特征参数显示区域；
- 频率最低点、超调量及恢复时间。

支持正向、反向拖动、精细步进与直接输入数值。

滑块移动到未预先采样的位置时，应按照实际参数重新计算，不允许只利用附近曲线做粗略近似代替真实响应。

### 6.3 基准工况比较

提供“设为基准”“恢复基准”和“显示/隐藏基准”功能。

用户可以固定一组基准参数，再移动滑块研究其他工况，在两幅图中同步比较基准与当前工况。

## 7. 功能五：实时特征参数与动态性能显示

在双图下方或侧边设置特征参数面板。

**核心四类特征量：**

| 特征量 | 显示要求 |
|---|---|
| 自然频率 ωₙ | 当前数值及单位 rad/s |
| 阻尼比 ζ | 当前数值和阻尼状态 |
| 闭环极点 p | p₁、p₂ 的实部、虚部及模长 |
| 闭环零点 z | 实际零点位置；必要时说明相消状态 |

**扩展性能指标：**

频率最低点 f_min、最低点时刻 t_n、超调量 M_p、2% 整定时间 t_s、初始 RoCoF、准稳态频率 f_∞、闭环主导极点实部绝对值。

同时提供当前扫描变量的特征量变化范围，必要时可以展开小型趋势曲线，显示 ωₙ、ζ、零极点位置及相关性能指标如何随变量变化。

## 8. 数值计算与正确性要求

### 8.1 计算方法

建立统一的数学计算模块，完成传递函数系数计算、特征根求解、零点求解、阶跃响应计算及性能指标提取。

优先使用完整闭环传递函数或等价状态方程，不能只使用标准无零点二阶系统的超调量公式。

需要正确处理欠阻尼、临界阻尼、过阻尼、极点重合及 F_H=1 时的模型降阶。

### 8.2 交叉验证

使用独立 Python 程序对网页计算结果进行核对。至少覆盖：

- T₁=T₂ 与 T₁≠T₂；
- 三种 λ 变化路径；
- F_H=0、0<F_H<1、F_H=1；
- 欠阻尼、临界阻尼和过阻尼；
- D、H、T_R、K_F 单独变化；
- 零点固定、零点移动和极零相消。

核对内容包括极点、零点、自然频率、阻尼比、频率响应曲线以及实际动态指标。

还需验证初始频率变化率、准稳态频差等解析关系，作为程序正确性的基础检查。

## 9. 页面设计与技术实现

采用简约、清晰的学术分析工具风格，以双图为视觉中心，避免过多装饰性界面元素。

建议采用以下布局：

**顶部：** 模型名称、当前场景、参数配置与导入导出。

**左侧参数区：** 基础参数、扫描变量、变化范围及变化路径。

**中央双图区：** 零极点参数轨迹与频率响应曲线簇。

**下方交互区：** Slider、基准比较、关键特征量及性能指标。

**底部：** 计算说明、数据导出和模型适用范围。

技术上采用 HTML、CSS、JavaScript 和成熟的交互绘图库实现。数值计算模块与界面绘制模块应相互独立，便于后续扩展和科研复现。

## 10. 开发阶段与交付成果

**阶段一：模型计算内核。** 完成参数体系、传递函数、零极点及频率响应计算，并通过独立程序验证。

**阶段二：双图与交互界面。** 完成轨迹绘制、响应曲线簇、点击选取、参数滑块和实时信息显示。

**阶段三：场景和数据管理。** 完成物理参数范围校验、三种 λ 扫描路径、基准比较及数据导出。

**阶段四：网页部署与测试。** 部署静态网页，在主流桌面浏览器中检查操作与绘图正确性。

最终交付包括：

1. 可直接访问和使用的 HTML 网页。
2. 完整 HTML/CSS/JavaScript 源码。
3. Python 独立验证程序。
4. 参数配置文件与典型测试工况。
5. 图形及原始数值 CSV/JSON 导出功能。
6. 简明操作说明和计算正确性测试记录。

**最终验收标准：** 用户能够自主输入参数初始值及范围，选择任意支持的扫描模式，在闭环零极点图中点击任意有效轨迹位置或移动滑块，并准确、同步地观察零极点、特征参数和完整频率响应的变化，所有结果可保存并通过独立程序复算。
